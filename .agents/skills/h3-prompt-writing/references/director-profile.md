# Director 的 H3 项目差异

本页是 Director 对官方 H3 格式的项目约定。官方 `base-en.txt`、`ref-en.txt` 保留为上游快照；在 Director 中编译、修订和校验时应用本页差异。字段、参考标签和首尾帧对齐声明仍按所选官方模式。

## 内容与详细程度

新写和修改都应用 [内容取舍与多轮修订](prompt-composition.md)，该页是跨作品的内容主次、控制篇幅和重写方法的唯一来源。核心动作、表演、对白与信息变化优先；反复出现且仍适用的异常只留必要控制。

上游 Ref2VA 的 “as detailed and explicit as possible” 在此解释为执行所需的信息清楚，不要求穷举细节；350–500 英文词是上游写作建议，不是本项目的最低字数或交付目标。简单镜头不凑字数，复杂镜头不为压缩删必要过程。格式要求的六段、参考关系与完整对白仍须保留；具体接口若有长度上限，另按实际能力核对。

## 当前本地参考路线

本地有参考时按 Ref2VA 编译，单图同样是参考，不是首帧端口。默认完整人物、场景和道具参考加动作描述，不强制首尾图。跨生成段优先设计切镜；必须同一人连续动作时按本地流程准备前段采用切点前的视频参考，描述从末尾状态继续，不另强制尾帧图片。参考读取范围、声音与时长按 [本地能力](../../../../docs/workflow/references/local-model-capabilities.md)。以下首尾帧对齐规则只用于另一个实际支持那些端口的工作流。

## 镜序与时长

- 普通生成默认使用 `director` profile 的 `ordered` timing。只写连续镜号，用动作、视线或声音交代承接，具体切点由模型决定。
- 固定主音轨的音频驱动多镜头默认使用 `exact` timing。其他任务在用户需要精确切点且入口支持时也用此格式。第一镜写 `[Shot 1]`，第二镜起写 `[Shot N] At MM:SS.mmm, ...`。切点取自最终输入音频的本段时间轴，按输出帧率对齐，递增且早于总时长。
- 先确定最终使用的完整主音轨，再实测每轮对白的起止、换人停顿和尾部留白。剪过停顿就重新测时。同一人连续说话时把句内停顿写在同一个 Shot 内。每个 Shot 写清景别、谁在画面里、谁说话、对方的反应和下一镜的触发点。双人同框时给正在听的人一个可见的闭口反应。精确时间戳是生成提示，按实际出片核对切点和口型归属。
- I2VA、FL2VA、L2VA 保留必要的首帧或尾帧对齐声明；这些声明不等于给中间切镜加时间戳。
- 有效时长、参考组合和参数以实际节点或 API 为准。官方托管 API 的时长区间不能直接套到本地工作流；本地先解析帧数与帧率，再让声明、参数和校验使用同一有效时长。

## 表演、摄影与声音

- 写清固定机位，或运镜类型、方向、速度和最后构图。跟拍写明跟谁；同一镜的连续运动和动作阶段留在同一镜内。
- 关键表情、持物或接触应能看清。反应镜写触发、情绪、可见反应和落点；接触写谁用哪只手碰到哪里，以及最后状态。
- 中文对白逐字放入 `<d>`，保留原文字词、标点与语言标签，不为了套英文句末示例改写原句；说话人、表演和声线放在标签外。完整发声的 `</d>` 后加 `[END_OF_DIALOGUE]`；跨镜未完句等说完再加。它是项目试验项，若被念出，用保留旧版的单变量对照验证，不宣称为官方语法或已保证有效。
- 给对白、停顿和反应留时间。音效、环境声和配乐的起落用动作或事件说明。无精确切点时不伪造逐镜发声窗口。
- 核对实际参考顺序、文件版本和用途。画面及动作描述默认用英文，用户指定中文时用中文，保留字段名、参考标签与对白标记；对白、歌词和画内文字保留原文。出片后核对动作终点、对白和前后镜连续性；返工保留上一版。

构图、空间关系与状态变化的写法见 [镜头描述](../../h3-cinematic-director/references/shot-description.md)。出片异常按 [共性问题排查](../../../../docs/workflow/references/h3-prompt-diagnosis.md) 取证；新写和多轮返工都按上述内容取舍规则整理，不等到出现字面冲突才清理。

## 编译与校验用同一模式

将 `profile`、`timing`、实际模式和有效时长放在提示词外的制作说明中，不作为额外 H3 字段。普通 Director 提示词使用：

```sh
python3 <minimax-h3-prompt-writer技能目录>/scripts/lint_prompt.py <prompt.txt> --mode t2va --duration 6 --profile director
```

精确切点加 `--timing exact`。检查未应用项目差异的官方示例时用 `--profile official`，默认采用 `exact`。校验只检查文本结构与可计算关系，不证明模型能按时切镜、准确说话或保持连续性。
