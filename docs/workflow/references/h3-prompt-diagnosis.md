# H3 提示词的共性问题与排查

本页归纳本地 H3 Ref2VA 制作中的反复偏差，用于写提示词前检查和出片后定位原因。具体镜号、提示词版本、参考文件与样片证据保留在作品记录里。写法见 [07 H3 视频提示词](../07-h3-prompts.md)，快速试片见 [08 视频生成](../08-toonflow-generation.md#用-04mp-快速调试)。

## 先分清原因

先核对实际提交的提示词、参考顺序与参数，再判断画面。画布里显示的文案、连线和生成任务收到的输入需要一致。

1. **文字或来源冲突可以直接查证。** 全局要求人物已经在场，逐镜又要求从空位出现；人物板保留装备的描述与剧情中的持物状态冲突；旧设定和新分镜使用不同特效颜色。先统一当前事实，再生成。
2. **空间或取景歧义需要结合参考判断。** 单个名词都对，组合起来仍可能要求同一画框看见不同高度、距离或遮挡后的东西。用本镜机位检查这些关系能否同时成立。
3. **模型倾向要由样片支持。** 本地样片出现过辅助物件抢画面、宽景吞掉表情、状态变化被简化等现象。文字、参考、构图和分辨率可能共同影响结果，不能仅凭一次成败确定是哪一项造成的。

对照测试尽量固定参考、预设、画幅和时长；节点暴露种子时一并记录。一次只验证一个主要假设，有助于定位原因。已经确认的多处矛盾可以一起清理，但只能把结果记为整版改善，不能据此证明某个词或某张图是唯一原因。排除输入错误后仍反复偏离，再记录为该工作流下待验证的模型倾向。

## 常见症状与处理

| 症状 | 优先分析的原因 | 处理与验证 |
| --- | --- | --- |
| 人物远景、脸小，身份或情绪读不出 | 取景任务冲突：正文既要完整房间、双人站位或腿脚动作，又要面部细节。低分辨率下，小脸可用像素更少 | 按观看任务写清画框边界，背景只留必要地标。人物离对手远，不代表摄影机也要拍远。先修取景，再看是否需要提高交付分辨率；检查第一个稳定画面、对白过程和结尾。空位揭示、走位或空间建立仍可用全景 |
| 人物像站起、缩小，物件和身体挤到同一高度 | 姿态、承托面、高差或遮挡没有交代清楚；同时要求多个部位和物件完整入画，使构图与空间关系不相容 | 先定人物姿态和物件所在平面，再确定机位能看见的动作。保留必要局部，其他状态可在画外延续。跨机位比较相对关系，不比较它们在画面上的绝对高度 |
| 修好姿态却把镜头引向腿、椅子或地板 | 用来解释姿态的辅助部位，被正文写成了拍摄目标；俯视参考也可能影响构图 | 先写动作主体和关键落点，再补支撑关系。检查机位是否看得到动作，而非只堆「右前方、俯拍」等方向词。返工后复查画面重点和闲置手的状态 |
| 表情镜出现无关前景道具，或背景朝向不对 | 多张参考的职责重叠；道具特写过于突出；场景参考的实际视向与本镜不符 | 检查真实输入，按本段用途移除无关图或换同向视图，同步标签和连线。保留完整参考的信息，不等于每段挂齐全部资产。参考取舍见 [05](../05-image-references.md) |
| 人物身份混乱，多视图的小脸影响特写 | 参考板中不同大小、角度的面部提供了不一致的身份线索 | 用清晰面部特写负责身份，全身视图负责体态与服装。有意遮住小脸的黑框按 [人物板经验](../05-image-references.md#人物多视图里的面部遮挡) 保留，检查版式是否误入成片 |
| 显形变成上升入画，或人物已经存在后才增加光效 | 「出现」混合了进入画面、身体位移、形体可见性和表面纹理几种变化；全局起态也可能与逐镜冲突 | 分别写起态、可见的中间过程和终态，只改变剧情需要的属性。检查主体定义、保留分析和逐镜正文是否一致。验收取变化前、中、后三段证据，不能只看最终人物是否好看 |
| 特效、造型或道具状态跨段不一致 | 剧本、视觉设定、分镜、参考和节点文案仍混用新旧版本；保留描述无意中固定了本应变化的状态 | 先确定当前采用版本，同步仍在使用的来源与提示词。写清效果的颜色、范围、强度和触发条件，分开稳定属性与阶段变化；对照相邻段采用切点 |
| 人物干站着，动作像逐项执行，片段拖沓 | 对白与动作彼此分离；每个微动作都单独停顿；生成时长超过当前内容所需。联合生成的节奏表现也需实测 | 让视线、呼吸、上身动作和对白按因果交叠，衣发随真实动作短暂跟随。按实读对白和关键动作调整时长，删除无作用的等待；不把某次长段压短的比例当成通用参数 |
| 对白连续重复称呼、情绪一遍遍重说 | 剧本没有把认人、试探、追问等不同意图分开；提示词不能替剧本解决这类重复 | 在已授权的剧本修改范围内调整称呼和句意，让肢体反应承接没说完的意思。采用后同步分镜与提示词；只改提示词的任务保留已定台词 |
| 跨段人物姿态跳变，或反复做同一动作 | 两次独立生成被要求在相同构图里严丝合缝；后段又从动作起点重演 | 优先按 [切镜接口](../06-storyboard.md#跨生成段的剪辑接口) 换取景并保持状态连续。确需同一动作接续时按 [本地接续规格](local-model-capabilities.md#两段视频怎么衔接) 截取参考片段，并写明从末尾继续；以两段连播判断接镜 |

## 修订时整理当前版本

发现局部歧义时改对应句，通读整段确认没有新冲突。经过多轮补丁，若全局条件、参考保留项与逐镜正文已经互相打架，就按当前分镜重新整理参考职责、共同条件和逐镜动作，保留已验证有效的对白与动作。删掉旧方案残句、同义重复和无关限制，不用更长的否定清单盖住矛盾。

将修订同步到提示词文件、文档和实际生成节点；涉及事实变化时回填负责的剧本、视觉设定或分镜。旧版本与旧 take 归档留作对照，生成只使用一版明确的当前输入。

## 用证据判断是否修好

按镜头职责验收。露脸清楚、对白完整，并不能抵消错误的出现方式、人物高度、持物状态或缺失的关键动作。用窄画框隐藏无关部位可以减少干扰，但如果本镜必须证明交接、接触或空位，就要让证据可见；画外没有展示某人，不足以证明那处空间无人。

总览用于定位疑点，关键接触和状态变化用原尺寸帧加密检查，时间或帧号对应原视频。剪辑可修要有实际可用区间，并验证剧情动作、尾音和下一镜仍能接上。转写用于筛查漏句，无对白段落里的低置信度文字需结合原声、语音活动检测等复核，不能直接当成生成了新台词。完整验收方法见 [09](../09-video-review.md)。
