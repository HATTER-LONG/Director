01–04 的故事、对白、感知权限和稳定资产归属可沿用。05–06 补齐构图帧的限定用途与重复机位依据；07 收敛为执行路线；08–09 保留输入回读、恢复和分层验收，接入统一的文字整理与验证规则。来源文档、派生数据、节点和旧 take 的职责保持区分。

## 组织后的读取路线

- 新写或修改：AGENTS → 07 → 视频提示词技能与 H3 格式入口 → 所选模式、profile、内容取舍。
- 出片异常：09 → 按症状排查 → 只修有证据的来源、参考、设计或文字 → 回到同一 H3 编译入口。
- 实际生成：08 核对真实正文、引用和参数，再按授权提交；文本检查、产物存在、成片可用、创作者采用分别记录。
- 新经验：作品保留具体证据 → 共用条目提炼适用条件 → 更新唯一负责处及调用链接。新增经验优先修正现有条目，不按每个失败新建永久规则。

本页是一次审查记录，不作为新增规则源；后续规则以所链接的负责文档为准。

## 复核与边界

- 对审查入口与改动文件检查本地链接、标题锚点和代码围栏；未发现失效引用。
- 四个修改了 SKILL.md 的技能通过 skill-creator 的 quick_validate。已有用户修改作为本轮基线保留。
- 用两条合成提示词检查 Ref2VA 与 T2VA：保留所需字段、逐字中文对白、说话人和有序镜号，均通过现有 H3 linter；删除必需字段的反例会报错。没有将短文本本身当作成功证据。
- 按新写、单句修订、多轮膨胀、重复机位和局部状态变化五种入口做人工桌面推演：分别落到同一写作规则或负责阶段，不自动增加生成、改对白、删关键动作或固定所有视角的屏幕左右。
- 篇幅比例与控制的语义归类仍需人工检查，现有 linter 不验证它们。未进行新的生成对照，不能声称这些写法已经改善成片或能保证不同 Agent 一致表现；后续按实际证据继续迭代。
