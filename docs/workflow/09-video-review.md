# 09 视频验收与返工

有实际生成视频，需要验收、选 take 或决定是否重跑时，读本页。用当前剧本、分镜和参考版本对照生成结果。

## 使用 Skill

- [continuity-checking](../../.agents/skills/continuity-checking/SKILL.md) 检查人物、道具和前后镜连续性。[shot-sequencing](../../.agents/skills/shot-sequencing/SKILL.md) 帮助判断切点和镜序。
- [h3-cinematic-director](../../.agents/skills/h3-cinematic-director/SKILL.md) 修订表演与摄影。按需用 [minimax-h3-prompt-writer](../../.agents/skills/minimax-h3-prompt-writer/SKILL.md) 查参考、对白和声音，用 [minimax-h3](../../.agents/skills/minimax-h3/SKILL.md) 查本地工作流。需要专项审查时用 [short-drama-review](../../.agents/skills/short-drama-review/SKILL.md)。

需要判断观众是否看懂时，先只看本版成片复述事件、人物关系和转折，不提前读取创作者解释或上一轮评价；再对照剧本找误读原因。技术连续性检查仍读取实际参考、镜头要求和相邻 take。独立审阅与自检如实区分，不固定设置四个常驻代理。

## 操作

1. **先定位。** 确认实际文件、take、分镜和这次挂载的参考。能播放原片时，先原速带声看一遍，核对动作和对白。只审画面或批量比较 take 时，先把代表帧排成一张带时间的接触表。优先取首尾、段内切点两侧和关键动作落点，再对疑点补帧。等距抽帧容易漏掉短暂故障。
2. **再核切点。** 将切前最后一帧、切后第一帧、切后构图稳定的一帧并排，旁边另放实际挂载的场景主图、平面图或道具参考。保留原画幅并标清来源、时间或帧号。段内切镜和跨生成段的接镜都用同一方法。跨段优先看预定采用的出点和入点。各格保留独立原图，拼成审核板即可。
3. **用原片复核有疑问的位置。** 先原速看切点前后一小段，再用慢放或逐帧检查动作、视线、持物方向、闪烁和变形。对白、说话人、口型、声音跨切点和停顿都要回到带声原片。可用转写筛查漏句，读音和声线仍以原声为准。只有抽帧时，结论限于可见画面。
4. **按证据决定怎么修。** 在作品验收记录里写镜号、take、时间或帧号、可见变化和影响，并注明证据来自生成预览、抽帧还是原片。能改入出点、用声音桥或后期补齐的，先标可用区间。需要重跑时保留原 take，一次优先改一个变量，复审用同一组锚点和动作阶段比对。多项条件同时变化时，只评价整体差异，单项影响留待对照验证。
5. **按原因退回对应阶段。** 按 [共性问题排查](references/h3-prompt-diagnosis.md) 区分来源冲突、空间歧义、取景和参考问题，修到对应文档与实际输入。动作或对白偏差查 [H3 提示词](07-h3-prompts.md)，报错、错参或输出缺失查[生成记录](08-toonflow-generation.md)。补跑按本次授权执行，出片后按同一证据标准复查。

### 按问题选证据

| 方法 | 最适合 | 容易漏掉 |
| --- | --- | --- |
| 带时间接触表 | 批量扫多条 take，定位身份、构图、文字和道具状态变化 | 两帧之间的故障、动作是否连贯、声音 |
| 切点前后帧＋原始参考 | 核实轴线、站位和道具。先对比固定地标，再看人物、接触点和道具与地标的关系 | 画外位置、连续运动。换机位后以场景中的相对关系判断 |
| 原片回放、慢放或逐帧 | 确认观感，查表演节奏、动作过程、画音关系和短暂缺陷 | 单靠回放难以准确对照不同 take 的固定物位置，遇到疑点回看并排图 |
| 生成中的预览 | 及早发现明显的构图、站位或物件偏差 | 导出质量、完整动作和声音。预览只提供线索，正式验收以导出片为准 |

跨角度核对时，先找两镜都能看见的地标或接触点。只在一镜可见的物件用同向参考确认。文字、手和道具等细节回原尺寸帧复核，检查文字是否完整、道具是否重复、人物与物件是否保持应有的接触关系。

无对白片段被转写出零星文字时，先查置信度和原声，必要时加语音活动检测。转写可能把噪声认成词，语音检测也不能单独证明音轨完全无发声。没有听审条件时记录筛查结果，不把它写成已完成声线、混音或精确口型验收。

承担身份辨认、对白或情绪的镜头，按实际输出尺寸检查第一个稳定画面、说话过程和结尾，确认眼神、嘴型与表情可辨。不能只凭提示词写了「近景」就判定通过；还要检查实际画框是否拉远，带入了不该出现的肢体或道具状态。取景修订见 [H3 的构图注意](../../.agents/skills/h3-cinematic-director/references/shot-description.md#h3-的构图注意动作主体与辅助元素)。

人物与环境的高差、动作方式、持物状态和跨镜特效若违背已定情节、改变观众理解，应判为需修复。对白完整或脸部清楚不能抵消这类问题。归为剪辑可修时，先找到保留剧情动作与完整声音的可用区间，并验证接镜；没有可用区间再重跑。

### 验收结论的范围

分别记录技术检查、静态画面检查、动态与剪辑检查、声音听审和创作者采用。只取得文件或抽帧时，不宣称完成所有验收。环境视频可以只选用经核对的静态帧，记录整段不可用的原因与帧的限定用途；声音无法听审时，整条音轨可作为候选交付，但不绑定为已确认声线。

先检查会改变故事或空间的错误，再检查美术细节：人物身份与感知权限、关键文字、设备和道具状态、固定布局、动作可达性。主要设计被删掉与地理关系正确应分别判断。严重来源冲突且现有依据不能裁决时，停止受影响的生成并把具体冲突交给用户；继续不依赖该决定的文档、检查或素材整理。已有明确修正依据的常规返工按授权执行。

### 跨段接镜

把前段采用切点与后段开头连播，再看后段构图稳定时及动作或对白结束时的状态。换景别、角度或人物的切镜按视线、持物、光向、动作阶段和声音关系判断，不要求两侧画面像素一致。确需同一人的连续动作时，对照实际挂入的 [接续参考](references/local-model-capabilities.md#两段视频怎么衔接)，检查是否从其末尾继续，有无重新起手、速度突变或动作重演。

特效有阶段变化时，按变化前、变化中和稳定后取帧，核对作用范围、颜色与背景地标。声音桥还要回听两侧发声、音效与动作落点。优先试已有素材的入出点和声音衔接，无法保留剧情所需内容再返工。

### 手机竖屏安全区

在目标播放界面上检查遮挡。界面未知时，用可调整的上下遮挡示意做初审。看相关镜头的起点、动作最远处、回落点与切点，确认眼神、口型、手势和画内文字仍能读清。具体范围按实际界面和构图确定。

### 本机快速抽帧

在 Toonflow 里，可从视频节点打开「逐帧拉片」，先用本地检测定位候选切点。它每镜只导出一张接近中间时刻的关键帧，也能导出分镜视频和原音轨。查接镜时，按候选切点回原视频补抽两侧的帧。

把 `clip` 设为待审视频的路径。下面两条 FFmpeg 命令分别生成一张 15 秒以内片段的等距总览，以及列出画面突变的候选时刻。自动检出的 `pts_time` 只是复查起点，快速运动或闪光也会触发，弱切换也可能漏掉。

```sh
ffmpeg -v error -i "$clip" -an \
  -vf "select='isnan(prev_selected_t)+gte(t-prev_selected_t,2)',scale=240:-2,drawtext=text='%{pts} s':x=8:y=8:fontsize=18:fontcolor=white:box=1:boxcolor=black@0.7,tile=4x2:padding=6:margin=6" \
  -frames:v 1 -update 1 review-overview.jpg

ffmpeg -hide_banner -i "$clip" -an \
  -vf "select='gt(scene,0.18)',showinfo" -f null - 2>&1 | rg 'pts_time:'
```

总览取样后，补实际尾帧和已确认切点的前后帧。接触表的时间应来自原片 PTS；改变采样帧率或重置时间戳后，不能把样本序号当原片秒数。`showinfo` 在筛选后的 `n` 是候选的序号，定位原片用 `pts_time`。已确定原片帧号时，把 `frame` 设为从 0 起算的帧号，用下面的命令导出原尺寸 PNG。

```sh
ffmpeg -v error -i "$clip" -vf "select=eq(n\\,$frame)" \
  -frames:v 1 -update 1 "review-frame-$frame.png"
```

## 交付

在作品验收记录中列出采用 take、文件位置、可用入出点、预览或交付规格，以及需要修复的镜头，保留对照版本及改动项。预览通过说明当前试片完成了哪些检查；切换规格重新生成后，按 [生成流程](08-toonflow-generation.md#用-04mp-快速调试) 复核新文件。只交生成视频时，到可播放视频和验收记录为止。用户另要成片时，将选片交给 [short-drama-edit](../../.agents/skills/short-drama-edit/SKILL.md)。
