# 动作摄影与布局参考

用于接触、追逐、重心变化和布局图转译。按当前镜头的观看任务选用方法，不规定统一景别、运镜或提示词格式。

## 让力量与接触可读

先确定这镜需要证明什么。要看清握持变化，用局部近景；要判断身体怎样承重、越过障碍或完成碰撞，则让支撑点、双方距离和反应进入可见范围。必要时放宽景别或另设交代镜，不因出现武器或身体动作就一律拍全身。

动作的启动、接触、后果和收势应有足够证据。晃动、模糊、速度线或碎屑可以加强感受，但不能独自代替接触和结果。声音按已定声音方案交给生成或剪辑阶段处理。

## 摄影机与移动人物

人物行走、奔跑、追逐、上下楼或经过不平地面时，先选固定观察还是跟随，再判断运动是否可信：

- 跟拍写清跟随对象、平均方向、相对速度和停点，可保留自然的滞后与调整，不必每一步同步起伏。
- 固定机位让人物在画内移动，用背景地标、遮挡和大小变化体现距离。
- 只有需要证明落脚、支撑或接触时才必须看见相关部位。头肩近景可通过上身位移和衣发跟随表达移动。
- 背景视差与模糊应符合摄影机和人物的相对运动。人物跑出画框、摄影机追上或减速，都应服务追逐关系或信息揭示。

## 动作中的注意转移

双人接触或追逐可从发起者的准备动作，转向接触点，再转向承受者的反应。跟随对象在一个阶段内保持明确；是否切镜、减速、暂时固定或继续跟随，由观众需要看见的变化决定。

环绕用于揭示接触面、力量关系或新距离，升降由跳跃、跌落或高度变化等可见事件带动。前景衣物、武器或其他物件短暂遮挡后，应重新建立人物数量、轴线和空间关系。需要说明交接或碰撞结果时，遮挡不能掩盖关键过程。

## 固定场景与换机位

共同布局用场景方位与物件关系记录，例如「门在北墙，桌在门东侧，通道沿西墙」。人物位置、身体朝向、视线目标和移动方向分别记录。画面左右由当前机位推导，换到反打后不能继续沿用上一镜的屏幕坐标。

交代镜展示必要空间，近景和插镜只保留本镜需要的地标、接触点与方向。切镜可通过视线、动作或声音承接，无需每次回到全景。改变机位时明确哪些位置保持、哪些动作已经发生，不能用裁切掩盖剧情所需的位移或持物变化。

布局图负责几何，人物图负责身份，材质与光色按采用的视觉设定。参考用途和实际输入共同核对；本地 H3 的构图诊断见 [提示词流程](../../h3-cinematic-director/references/shot-description.md#h3-的构图注意动作主体与辅助元素)。

## 抽象布局图如何转成拍摄描述

使用平面图、CAD 或色块图时，先读出物件占地、前后遮挡、通路、长轴方向和人物朝向，再转成当前机位下可见的关系。长桌、桥梁、车辆等需要说明朝向或两端位置，只有一个中心点不足以交代动作。

图中文字、箭头、网格和色块只帮助理解布局。实际镜头另写机位与取景，避免让模型把俯视示意图直接做成成片。参考标签按目标模型编译，不在本页规定另一套语法。
