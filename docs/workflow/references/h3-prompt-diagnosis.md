# H3 提示词的共性问题与排查

本页归纳 H3 制作中可迁移的偏差与检查方法，用于按症状定位，不是默认粘进提示词的禁令库。观察主要来自本地 Ref2VA，换入口需重新验证；表中原因均是待查方向，不表示已经证明因果。具体镜号、提示词版本、参考文件与样片证据保留在作品记录里。写法见 [07 H3 视频提示词](../07-h3-prompts.md)，快速试片见 [08 视频生成](../08-toonflow-generation.md#用-04mp-快速调试)。

## 先分清原因

先核对实际提交的提示词、参考顺序与参数，再判断画面。画布里显示的文案、连线和生成任务收到的输入需要一致。

1. **文字或来源冲突可以直接查证。** 全局要求人物已经在场，逐镜又要求从空位出现；人物板保留装备的描述与剧情中的持物状态冲突；旧设定和新分镜使用不同特效颜色。先统一当前事实，再生成。
2. **空间或取景歧义需要结合参考判断。** 单个名词都对，组合起来仍可能要求同一画框看见不同高度、距离或遮挡后的东西。用本镜机位检查这些关系能否同时成立。
3. **模型倾向要由样片支持。** 本地样片出现过辅助物件抢画面、宽景吞掉表情、状态变化被简化等现象。文字、参考、构图和分辨率可能共同影响结果，不能仅凭一次成败确定是哪一项造成的。

对照测试尽量固定参考、预设、画幅和时长；节点支持固定种子时，比较修订前后版本使用相同种子，暂时关闭成功后自动换种子的选项，并记录各次实际提交值，测试结束后恢复既定种子策略。固定种子用于减少比较变量，不保证输出完全一致。一次只验证一个主要假设，有助于定位原因。已经确认的多处矛盾可以一起清理，但只能把结果记为整版改善，不能据此证明某个词或某张图是唯一原因。排除输入错误后仍反复偏离，再记录为该工作流下待验证的模型倾向。

## 围绕本镜重点编写

初稿和返工统一读 [H3 内容取舍与多轮修订](../../../.agents/skills/h3-prompt-writing/references/prompt-composition.md)：先写本段要表达的内容，再补必要事实和异常控制，并检查两者篇幅。本页只维护症状、排查方向和验证证据，不另存一份写作规则。

## 常见症状与处理

| 症状 | 优先分析的原因 | 处理与验证 |
| --- | --- | --- |
| 人物远景、脸小，身份或情绪读不出 | 取景任务冲突：正文既要完整房间、双人站位或腿脚动作，又要面部细节。低分辨率下，小脸可用像素更少 | 按观看任务写清画框边界，背景只留必要地标。人物离对手远，不代表摄影机也要拍远。先修取景，再看是否需要提高交付分辨率；检查第一个稳定画面、对白过程和结尾。空位揭示、走位或空间建立仍可用全景 |
| 人物像站起、缩小，物件和身体挤到同一高度 | 姿态、承托面、高差或遮挡没有交代清楚；同时要求多个部位和物件完整入画，使构图与空间关系不相容 | 先定人物姿态和物件所在平面，再确定机位能看见的动作。保留必要局部，其他状态可在画外延续。跨机位比较相对关系，不比较它们在画面上的绝对高度 |
| 重复机位的人物与固定地标左右翻转 | 只声明世界方位而没有具体镜位依据；当前候选与历史采用帧混用；相反视图同时承担构图职责 | 按 [镜位依据](../06-storyboard.md#重复机位与画面左右) 确定观察侧与适用镜头，必要时复用同向构图帧。近景只收紧时保持该关系；真正反打重新推导，不把人物固定在所有视角的同一侧。按固定地标并排检查 |
| 同一人物移位后出现两份形体 | 起点与终点被写成同时在场；“立即重现”缺少原处结束条件；参考板或多个视图被误作多个人 | 核对同一主体绑定，按既定能力写完整先后与终态，只保留必要的单人控制。原位置、变化过程和新位置一起验收；若剧情允许分身或残影则按来源判断，不能一律禁止 |
| 人物随切镜忽隐忽现，或再次入画的位置无来由 | 混淆场内位置、当前取景与角色感知权限；不同生成段沿用互斥的在场描述 | 按 [人物在场与对白覆盖](../06-storyboard.md#人物在场与对白覆盖) 核对连续镜头与真实参考。先修来源和描述，再连播检查位置变化是否有依据；不能仅凭某镜没拍到人物就判定其消失 |
| 修好姿态却把镜头引向腿、椅子或地板 | 用来解释姿态的辅助部位，被正文写成了拍摄目标；俯视参考也可能影响构图 | 先写动作主体和关键落点，再补支撑关系。检查机位是否看得到动作，而非只堆「右前方、俯拍」等方向词。返工后复查画面重点和闲置手的状态 |
| 表情镜出现无关前景道具，或背景朝向不对 | 多张参考的职责重叠；道具特写过于突出；场景参考的实际视向与本镜不符 | 检查真实输入，按本段用途移除无关图或换同向视图，同步标签和连线。保留完整参考的信息，不等于每段挂齐全部资产。参考取舍见 [05](../05-image-references.md) |
| 人物身份混乱，多视图的小脸影响特写 | 参考板中不同大小、角度的面部提供了不一致的身份线索 | 用清晰面部特写负责身份，全身视图负责体态与服装。有意遮住小脸的黑框按 [人物板经验](../05-image-references.md#人物多视图里的面部遮挡) 保留，检查版式是否误入成片 |
| 显形变成上升入画，或人物已经存在后才增加光效 | 「出现」混合了进入画面、身体位移、形体可见性和表面纹理几种变化；全局起态也可能与逐镜冲突 | 分别写起态、可见的中间过程和终态，只改变剧情需要的属性。检查主体定义、保留分析和逐镜正文是否一致。验收取变化前、中、后三段证据，不能只看最终人物是否好看 |
| 持续造型或表面特效只在显形瞬间存在，侧背面又退成普通衣服 | 稳定外观被写成一次性到达效果；只写色光或轮廓，遗漏参考中实际可见的纹理与作用部位 | 对照真实素材区分轮廓光、表面纹理和短暂过渡，稳定属性在定义中写清，动作正文只重申易丢失的阶段。核对正面、可见侧背面及稳定后的画面；不靠延长禁令保证效果 |
| 特效、造型或道具状态跨段不一致 | 剧本、视觉设定、分镜、参考和节点文案仍混用新旧版本；保留描述无意中固定了本应变化的状态 | 先确定当前采用版本，同步仍在使用的来源与提示词。写清效果的颜色、范围、强度和触发条件，分开稳定属性与阶段变化；对照相邻段采用切点 |
| 手中多出物件，接触含混，或操作步骤反复重演 | 未交代双手是否空着、持有什么以及物件状态；参考外观被误作当前动作；连续段重复从操作起点开始 | 按 [动作取舍与手部状态](../06-storyboard.md#动作取舍与手部状态) 查左右手、接触点和终态，并核对参考用途。在授权范围内简化无戏剧意义的步骤后，检查必要动作是否仍完整。参考是否诱发多余持物须经对照验证 |
| 人物干站着，动作像逐项执行，片段拖沓 | 对白与动作彼此分离；每个微动作都单独停顿；生成时长超过当前内容所需。联合生成的节奏表现也需实测 | 让视线、呼吸、上身动作和对白按因果交叠，衣发随真实动作短暂跟随。按 [对白、动作与时长](../06-storyboard.md#对白动作与时长) 重估，删除无作用的等待；不把某段秒数或压短比例当成通用参数 |
| 台词文字完整，却落在另一人的画面；同框接话拖到切镜后 | 先查说话人与音频绑定、实际提交正文和切点。若绑定正确，再查接话是否被长动作说明隔开、是否先要求转头停住再发声，以及切镜条件是否明确 | 将每次发声与其说话人写在相邻位置，按需分段；同框对话写清听者闭嘴、下一人何时接话，以及哪句说完后才切镜。保留原对白和已定镜序；结合原声与切点两侧画面验证。自动转写能辅助定位语句，不能识别声线归属 |
| 多轮修改后重点难找，正文到处强调不同要求 | 同义约束和通用段落累积，核心动作、对白或终点被辅助细节隔开；不一定已有字面矛盾 | 按本镜职责重新组织一版全文，集中共同条件，写清核心事件的顺序，删去过期和无关内容。检查重要事实是否仍完整，再做对照；不能仅凭字数下降就宣称生成会改善 |
| 对白连续重复称呼、情绪一遍遍重说 | 剧本没有把认人、试探、追问等不同意图分开；提示词不能替剧本解决这类重复 | 在已授权的剧本修改范围内调整称呼和句意，让肢体反应承接没说完的意思。采用后同步分镜与提示词；只改提示词的任务保留已定台词 |
| 跨段人物姿态跳变，或反复做同一动作 | 两次独立生成被要求在相同构图里严丝合缝；后段又从动作起点重演 | 优先按 [切镜接口](../06-storyboard.md#跨生成段的剪辑接口) 换取景并保持状态连续。确需同一动作接续时按 [本地接续规格](local-model-capabilities.md#两段视频怎么衔接) 截取参考片段，并写明从末尾继续；以两段连播判断接镜 |

## 修订时整理当前版本

按 [多轮修改先替换再整合](../../../.agents/skills/h3-prompt-writing/references/prompt-composition.md#多轮修改先替换再整合) 修订，并沿 [07](../07-h3-prompts.md) 同步来源、正文与实际输入。无需等到补丁互相矛盾；重复、主次失衡或无关限制也足以触发整段整理。

区分已查证的问题、对原因的解释和待验证方案。正文冗长可以从文本确认；它是否导致串话、错位或拖拍仍需对照出片。未生成新样片时只报告已整理、已校验，不宣称修复有效。后续证据按 [经验迭代](production-principles.md#经验如何进入共用规则) 更新本表已有条目。

## 用证据判断是否修好

按镜头职责验收。露脸清楚、对白完整，并不能抵消错误的出现方式、人物高度、持物状态或缺失的关键动作。用窄画框隐藏无关部位可以减少干扰，但如果本镜必须证明交接、接触或空位，就要让证据可见；画外没有展示某人，不足以证明那处空间无人。

总览用于定位疑点，关键接触和状态变化用原尺寸帧加密检查，时间或帧号对应原视频。剪辑可修要有实际可用区间，并验证剧情动作、尾音和下一镜仍能接上。转写用于筛查漏句，无对白段落里的低置信度文字需结合原声、语音活动检测等复核，不能直接当成生成了新台词。完整验收方法见 [09](../09-video-review.md)。
