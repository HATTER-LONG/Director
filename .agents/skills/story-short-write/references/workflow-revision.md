# 短故事精修与交接

Director 适配：只在写完故事或收到精修请求时读取。保留作者已定的体裁、人物、视角、情节和交付范围，不因网文平台模板增加付费点、反转或情绪烈度。

先核对原稿与已有设计：关键情节点、人物选择、线索来源及知情顺序是否一致；开头提出的问题、关系或情绪是否在结尾得到相应处理。有反转才查反转，无反转就查其实际兑现。只补原计划遗漏的必要内容，不为凑小节长度增加任务、反应或回忆。

创作／改写故事稿默认在交稿前检查去味，按入口组合交 [story-deslop](../../story-deslop/SKILL.md)，由它统一维护表达、用笔、故事三层的方法和可选脚本。只读相关层，保留有功能的强情绪、生活细节和停顿；story-deslop 处理后不再跑另一套去味全流程。普通中文句法、用词和冗余按需交 [natural-zh-writing](../../natural-zh-writing/SKILL.md)。

上游附带的小说脚本只适用于其实际文件契约。Director 默认不运行全文件标点写回、不要求所有模式检测清零，也不因缺少专用 reviewer 或 narrative-writer 而停止。当前执行者按范围复读；单独审稿交 [short-drama-review](../../short-drama-review/SKILL.md) 时说明输入是故事文本，审查不自动改稿。

按实际交付要求核对字数、完整性与格式；剧本改编另按可拍摄性与时长核对。交付改后的稿件、少量必要的变化说明和未解决事项；未实际运行的检查不称为通过。已授权的修订继续完成，不重复要求用户批准相同范围。
