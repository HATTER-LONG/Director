# 视听设计交给视频提示词

本页负责保全设计意图，最终字段与标签由目标模型技能决定。H3 使用 [h3-prompt-writing](../../h3-prompt-writing/SKILL.md) 和 [Director profile](../../h3-prompt-writing/references/director-profile.md)；其他模型使用其实际入口规则，不额外包装通用六段模板。

## 内部检查项

- 参考：身份、服装、地点和道具各由什么真实输入控制。
- 起点与终点：人物、物件、视线、动作阶段以及下一镜需要接住的状态。
- 观看任务：本镜要让观众读到的动作、关系或情绪。
- 摄影：景别、机位、取景关系；固定或运动，运动的对象、路径、速度与最后构图。
- 动作：触发、可见变化、接触与后果；涉及重量时保留支撑、重心与收势。
- 声音：谁说什么、声源在画内还是画外、环境声和配乐何时变化。
- 接镜：动作、视线、方向或声音如何承接。

这些项用于查漏，只把本镜需要的内容写进模型正文。没有固定镜数、每秒动作数、景别配额或风格名称要求。单次连续动作的阶段不自动变成多个镜号。

## 失败后怎么改

先用实际素材定位是观看任务、空间、参考、时间容量还是生成执行的问题。保留已成功的状态，只修改造成问题的条件；上一版与实际输入留在作品记录中。缺少生成证据时，说明当前只能做文本检查。
