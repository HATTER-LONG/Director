# 通用生产原则

本页用于把生产观察转成可复用规则。具体作品、镜号、素材、提示词、参数和采用结论写回作品记录；共用规则保留适用条件、检查证据和处理方法。未经对照验证的模型倾向仍标为待验证，不写成质量保证。

## 先确定当前依据

开始一轮生成或返工，读取当前剧本、设定、采用素材和用户最新反馈，找出本轮要改变的内容与必须保留的内容。区分用户认可整张图、认可某项设计和只是提出候选。旧图片与新设定冲突时，明确旧图仍能控制哪些部分；不能将互斥信息一同交给模型自行取舍。

美术要求应能落到画面证据：年代和技术水平怎样影响设备形制，场所用途怎样影响布局，人物身份怎样影响服装和声音。风格词只是方向，不能代替这些事实。局部清理沿用户认可的主要设计进行，检查是否误删功能、空间密度或关键道具。

## 先生成素材，再集中剪辑

本轮需要的图片、视频、配音和音乐先完成生成、回收与用途检查，给生成任务留出本机算力、显存和内存。素材阶段可以查看和试听已有输出、记录缺口与剪辑意图；Remotion 时间线制作、Studio、预览和渲染安排在素材生成结束后，不与生成任务同时占用资源。不要为腾资源擅自结束其他人的任务或系统进程。

生成批次结束后确认队列和任务状态，按实际需要释放空闲模型与本轮启动的进程，再进入 Remotion 后期；遇到素材缺口则先保存剪辑进度，停止本轮 Remotion 预览或渲染，回到已授权的生成范围补齐素材，再继续剪辑。单卡模型切换与内存检查见 [本地模型能力](local-model-capabilities.md#tts-与-h3-切换时释放缓存)，素材授权与恢复见 [生产路由](production-routing.md)。

音频按模型的正常语速基准生成并保留原音；音频或视频需要变速时，素材齐备后在已选后期时间线上统一处理，避免生成和后期重复加速。速度范围、保留音高、停顿和字幕对齐见 [配音与时间对齐](voice-and-timing.md#语速只从明确的基准调整)。

## 让每份参考承担明确用途

身份、造型、空间、材质光色、机位构图、屏幕内容和音色可以分别由不同素材提供。每个维度说明主要依据及辅助依据，冲突先解决再挂载。参考应足以完成本镜任务，不为凑齐整套资产加入无关局部或相反构图。

跨视角检查用共同地标、前后面、遮挡和接触关系；方位名与文件名只是索引。换机位会改变画面左右，不应改变家具朝向或物件数量。画外未覆盖的事实用明确来源补足，不能把“没看见”写成“不存在”。确需建立多机位空间时，生产步骤见 [05](../05-image-references.md#场景素材生成)；纯色背景不触发完整空间建设。

## 来源改变后更新哪些地方

先修改拥有事实的来源：剧情和感知权限归剧本，稳定外观与声音方向归设定，取景和动作边界归分镜。随后查引用关系，更新受影响素材状态、提示词全文、参考清单、节点输入与配置。派生 JSON 或汇总表同步当前版本，不成为另一套互相矛盾的事实。

旧版保留来路并标为已替代，断开当前镜头的废弃输入；不在继续有效的正文中混放相反设定。不能完成更新的部分明确标为待同步，停止受影响的提交。修完后回读真实输入，检查采用路径与正文是否一致。

## 证据支持多大结论，就记录多大结论

| 已取得的证据 | 可以确认 | 仍不能据此确认 |
| --- | --- | --- |
| 任务成功、媒体可解码、实际尺寸与音轨 | 技术产物存在 | 美术、动作或声音符合要求 |
| 原尺寸图、关键帧与空间依据的对照 | 当前可见布局、身份、文字和静态状态 | 整段动作、看不见的区域和音色 |
| 原速原片、切点与动作过程 | 已看的动态、节奏和连续性 | 未听过的发声、其他台词下的声线稳定性 |
| 实际回听及角色间对照 | 已听样本的声线、发音、完整性和区分度 | 其他情绪与镜头必然复现 |
| 创作者明确采用 | 指定版本与用途被采用 | 后续换输入或重生成仍自动通过 |

记录候选、限定用途可用、创作者采用和已替代状态。检查允许按用途完成，未完成项明确列出；不为了写“全部通过”省略证据缺口。静态帧可用与源视频可用可以得出不同结论。

## 经验如何进入共用规则

每轮制作可在已有记录中留下实际输入、观察到的偏差、修订和验证范围；用户反馈也保留其限定范围。提炼时去掉作品名、人物、镜号和专用台词，只保留可迁移的条件、证据强度、处理方法与验收点。单次出片不能证明某个词是唯一原因，尚未重跑的改法仍是待验证方案。

先判断经验的适用层级：只适用于某种制作逻辑的步骤与取舍写入该 [模式 workflow](../../../AGENTS.md#先确定制作模式)；两种模式都成立的素材交接、证据、语速与时间对齐写入共用 references；实际节点和模型参数写入本地能力。画风细节、特定语速、音乐选择及某片的对白覆盖要求保留作品范围，不升格为全部模式的默认值。

通用方法再按职责落位：故事与感知边界进剧本流程，稳定外观进资产流程，机位与动作边界进分镜流程，内容取舍与控制篇幅进 [H3 写作参考](../../../.agents/skills/h3-prompt-writing/references/prompt-composition.md)，症状与验证方向进 [共性排查](h3-prompt-diagnosis.md)，保存和实际接线进生成流程。workflow 和技能入口只链接唯一维护处，不各抄一份。

更新前查已有条目，优先修正、合并或收窄适用条件；新证据推翻旧解释时替换旧结论，不把相反规则一起保留为现行要求。编辑约定、已观察现象、原因假设和受控对照结果分别表述。比例等写作约定可随经验调整，但不能写成模型效果定律，也不自动改动已采用作品。

更新后检查调用入口、相关规则和示例是否仍一致，跑与改动相称的链接、格式或行为检查。具体证据留作品，共用文档不建立逐轮追加的失败清单；需要审查记录时按本次范围留一份结论即可。

## 让生产过程可恢复

长任务中断、切换会话或交接前，在作品已有制作记录中更新一段续作摘要：当前阶段与范围、有效来源及版本、已完成项、未决项和下一步；已有生产任务再附任务 ID、状态与采用文件。恢复时先读摘要，再回查直接依赖的原文和实际任务状态。摘要只作索引，不复制全部正文、不取代负责文档，也不新增一套记忆系统。

实际提交前核对完整提示词、参考版本和顺序、模型、模式、时长、画幅与声音。格式校验有错误就先修复；校验与提交顺序应有明确阻断，不能在检查失败后继续执行生成命令。实际参数和任务 ID 记入作品，避免因刷新、空闲状态或超时重复提交。

新组合先在授权范围内做代表性验证。返工由具体证据驱动，优先修一个原因；多项同时变化时只评价整体结果。相同问题重复出现而没有新的修正依据时，停止原样重投。剧情或布局的关键冲突无法裁决时，向用户提交冲突与影响，继续独立工作。

沿用作品当前画布组织，让当前输入与历史候选清楚分开。单画布分区与多画布的选择统一见 [素材交接](media-handoff.md)，不在其他入口另立默认值；授权与恢复见 [生产路由](production-routing.md)。
