# 05 图片与参考素材

要补角色图、场景多机位图、道具图或本镜关键帧时，读本页。资产图从视觉设定出发。本镜起始帧或收尾帧从已定分镜出发。

## 使用 Skill

- [short-drama-image-prompts](../../.agents/skills/short-drama-image-prompts/SKILL.md) 写资产图提示词。
- [short-drama-storyboard](../../.agents/skills/short-drama-storyboard/SKILL.md) 写本镜的冻结关键帧。
- [scene-asset](../../.agents/skills/scene-asset/SKILL.md) 设计场景俯视图、固定空间布局和多机位参考。
- 用 [toonflow](../../.agents/skills/toonflow/SKILL.md) 操作已配置的画布图像节点，授权统一按 [生产路由](references/production-routing.md)。

默认准备完整人物、造型、场景和道具参考；人物无需预摆成首尾帧姿态。GPT Image 2.6 的实际尺寸、编辑方式及 9:16 构图帧处理见 [本地模型能力](references/local-model-capabilities.md#参考优先)。完整参考保留原画幅，只有确需构图帧才裁切，不能为了匹配视频比例裁掉参考里的身体、服装或空间信息。

每个生成段按镜头职责选图。完整参考保留素材自身的信息，不要求每段挂齐全部资产。专门的桌面、道具或局部图应对本段动作有明确用途。表情镜意外带入大幅前景物件时，核对实际输入与参考职责，移除无关参考并同步编号、连线和挂图表，再用样片验证。

### 人物多视图里的面部遮挡

用户的 H3 制作经验：同一人物板中，保留清楚的面部特写，在全身正面、侧面等视图的小脸上加黑框，可减少多个面部版本干扰身份参考。全身视图继续提供体态、服装、背面和装备信息。遇到这种素材，先检查是否有独立清楚的面部特写；若黑框是有意处理，保留原图，不当成损坏或缺脸自动补画。提示词说明面部身份取自特写，其他视图只取体态与造型，参考板的黑框和版式不进入成片。该经验来自用户生产观察，具体改善幅度留待同条件对照验证。

## 操作

1. 确认这张图的任务。身份图要认得出人，场景图要交代地理，起始帧要落实本镜的机位和站位。先找现成素材，再补缺失项。
2. 资产图按 Skill 写入 `图片提示词.md` 或现有文档，使用 `IMG-...` 定位。关键帧提示词跟对应镜头放在分镜中。只写提示词时交付可复制正文和挂图清单。
3. 用户授权生成时，按 [生产路由与授权](references/production-routing.md) 选择作品入口，检查图像节点、真实输入、模型和预设，再提交。收回结果后检查身份、构图、光向及道具。选中的文件放回作品素材库或约定目录。
4. 回填实际参考的文件、版本、用途和顺序。`REF-...` 表示真实可读的参考，`PLAN-...` 表示待落实的挂图计划。计划用于准备提示词，投产前要核对对应文件。

## 素材画布与验收状态

实际生成先在作品目录中的素材画布进行：人物、环境、道具、屏幕内容和声音试说各有生成节点，保留提示词、候选、原始视频、选帧和修订来路。已确认的文件单列为当前可用素材。默认将素材研发与镜头生产分成两张画布；用户指定沿用一张时，在原画布分区并断开废弃输入，不为满足默认流程另建画布。操作与交接见 [08](08-toonflow-generation.md#素材交接与镜头画布)。

每项素材至少记录实际文件、版本、用途、来源和检查结论。状态区分：候选、在限定用途下可用、创作者采用、已替代。缺少听审或动态验证时具体写明，不能用“已生成”代替“可用”。一项素材可在静态构图上可用，同时仍有动作或声音待检项。

## 场景素材生成

需要新建或重建同一空间的多机位资产时，默认按 **符合设定的俯视图 → 素材主视图 → 环境多机位视频 → 关键帧 → 优化后的环境素材图** 推进。已有通过检查的阶段可直接复用；只修一张图或用户只要静态稿时，不强制从头重做或自动生成视频。本流程维护生产次序，`scene-asset` 只补空间、美术和机位设计，结论回填现有视觉设定。

### 1. 从设定建立俯视图

先读当前剧本、世界与人物设定、已采用美术图及用户本轮反馈，提取年代与技术水平、场所用途、正规程度、画风、空间密度和剧情动作需求。用户指定喜欢某图时，写清保留项与修改项。清理杂乱可以减少碎纹理、重复小件和乱线，不等于删除主要设备、功能或改变场所气质。

从出入口、固定地标、家具朝向、主要光源及通道建立统一世界方位，沿用已有坐标；新场景可用上北下南。生成高质量严格俯视图，完整显示边界和开口，方向标注放图边。俯视图同时体现采用的画风和主要设计，不能只凭投影正确就通过。

验收查看实际图像：数量、相对位置、朝向、通道宽度与动作路径能否成立；是否混入不属于顶视的立面。顶视无法表达的垂直叠放、设备正面和高度，另用文字或立面参考说明，不把这些正面硬塞进顶视图。布局存在互斥版本且无法从已定来源判断时，暂停依赖它的生成，提交具体冲突。

### 2. 基于俯视图生成素材主视图

将俯视图作为空间依据，已有美术图作为材质、光色与设备形制依据，生成一个能说明场所用途、关键地标和主要设计的人眼高度视角。明确摄影机的位置、视向、可见前后面及遮挡。主图确定立面、设备高度、光色、材质和细节密度，不重新安排布局。

把主图逐项对回俯视图；看到的数量与被遮挡的数量分开记录。主图新增剧情必需的设备或更改位置时，先更新空间依据并重新检查两张图。两者一致后才扩展机位，避免把不确定布局放大成一整套素材。

### 3. 用主视图与俯视图生成环境机位视频

在素材生成授权内，按 [07](07-h3-prompts.md) 编译 H3，按 [08](08-toonflow-generation.md) 提交。俯视图管地理关系，主视图管立面、形制、光色与画风；正文写实际机位。先覆盖剧情需要的主视向、反打和关键操作局部，不机械做全周环绕。空间允许时可连续移动，狭窄或遮挡复杂时使用明确切换的机位。

每个机位写摄影机在哪一侧、朝哪里看、必须看见的地标和应被遮挡的物件。只改变观察位置，固定家具不能随相机转向或移动。默认空景，不让人物遮住需核对的结构。机位视频属于素材勘景，不自动授权正片段生成。其一致性、耗时和成本是否优于直接静态多视图，仍需同条件比较。

### 4. 选关键帧并重新生成环境素材图

回看视频并按切点、稳定构图和关键地标选帧，记录源文件、帧号或原始时间。比较投影、前后面、遮挡和固定物件关系，不凭机位名称判定正确。某段发生旋转或变形时，不因中间一帧好看就宣称整段可用；独立选用静态帧必须确认该帧本身的空间成立。

以选帧控制机位和构图，以采用主图控制美术，以俯视图核对布局，用已配置的生图工具补清晰度、材质及必要细节。视频抽帧不是新的空间权威，不能把已经漂移的摆设修饰得更精致。缺少可靠取景时先重选帧或修正机位视频。

### 5. 交叉检查后入库

把俯视图、主视图和所有采用机位并排，按同一组地标检查数量、朝向、门窗、通道、设备高度、光向和动作接触区域。反打要重算画面左右及可见面；无法从图中判断的区域标为未覆盖，必要时补图。空间、美术和剧情用途分别下结论，不能相互抵消。

每张采用图记录场景、状态、机位与视向、版本和用途，保存源视频与选帧来路。局部设备、屏幕内容、可动道具可单独成资产，说明它只控制哪一部分；例如界面图只控制显示内容，外壳和安装位置仍由场景图确定。静态对齐通过不保证后续视频动作正确，动态部分仍按镜头职责验收。

### 给视频镜头交接环境参考

- **全局布局**用平面图或一条共用描述交代。记录人物从哪进出、站在哪里、面向哪里，以及相邻地标之间的关系。优先保留影响走位、视线或接镜的地标。
- **动作局部**用俯视图、局部照片或统一描述交代。标清人物接触的位置、动作要经过的区域、常用道具与人之间的关系。图上如果是道具移动后的摆法，注明它对应动作的哪个阶段。
- **画面样子**用同向实景图、选定的构图帧或成片抽帧交代。分别注明只取材质和光色，还是还要沿用这个机位和画框。交给视频阶段时，把各参考的用途和优先关系一并交接，避免全景图里的偶然摆设和宽景构图盖过当前镜头的动作。

## 缺少人物声线时：描述、H3 试说与音频提取

先检查已有声音参考是否符合当前人物。需要新声线且已获素材生成授权时，在素材画布建立独立 H3 试说节点；明确禁止所有视频生成时不提交。单独授权声线样片不扩展到正片段。

1. **定义可听的声音特征。** 从人物年龄、体量、生活背景和说话习惯，写音区、共鸣、质感、咬字、口音和停顿习惯。与最易混淆的同剧角色对比，写出区别及过头的反例。把稳定音色与本场情绪分开：“紧张”“奸诈”等意图要落实为这次说话的节奏、气息或语调，不能变成永久喊叫或发抖。细则见 [声音方向](../../.agents/skills/short-drama-assets/references/voice-direction.md)。
2. **准备试说词与参考。** 选自然完整、能在当前节点时长内从容说完的短句，包含常用发音和停顿，避免只有一个情绪词或强烈喊叫。它是素材测试，不混入剧本。完整人物图控制身份，清楚的面部特写控制脸，小脸遮挡与版式不进入视频。正在更换不合适的音色时，不继续挂旧声线把新选型拉回去。
3. **生成独立试说视频。** 按 [07](07-h3-prompts.md) 编译并通过对应模式校验，回读实际配置和参考后提交。固定机位、单人近景、无遮挡口部、简单背景；开启声音，无配乐、第二说话人和明显噪声，保留句首句尾余量。登记任务 ID，按实际状态查询，避免重复提交。
4. **回听与角色对比。** 检查声线年龄、音区与质感、角色间区分度、发音和句尾完整性、说话人数、噪声及情绪强度。对照已有角色音频，不能只比较提示词。没有可听条件时可完成技术检查，并提取整条未裁切音轨供试听；明确标为未听审候选，不声称选型通过，也不猜测精确裁切区间。ASR、波形和音高测量不能替代听审。
5. **提取可用音频。** 用 FFprobe 确认音轨、实际时长、采样率和声道。听审后选清晰连续区间，通过工作区 FFmpeg 导出当前入口支持的格式，通常为 PCM WAV；保留原视频与原音轨，记录截取范围和处理。没有依据不变调、加速、拼接不同声线或重度降噪。提取后回听，核对起音、尾音和失真。
6. **登记并交接。** 在人物设定登记实际文件、来源、采用区间、用途和听审状态。已通过的音频只按声明范围控制音色等特征，不继承试说词、临时情绪、动作、噪声或空间。镜头画布载入采用音频后，按真实顺序绑定 `<Audio N>` 与本段说话人 `(Sx)`，同步正文和连线。未听审候选留在素材区，不接入正式镜头。

一次试说只能支持当前听到的声音结论；换台词、情绪后的稳定性仍需后续验证。生成文件、检查可用与最终采用分别记录。
