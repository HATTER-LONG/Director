# 通用生产原则

本页用于把生产观察转成可复用规则。具体作品、镜号、素材、提示词、参数和采用结论写回作品记录；共用规则保留适用条件、检查证据和处理方法。未经对照验证的模型倾向仍标为待验证，不写成质量保证。

## 先确定当前依据

开始一轮生成或返工，读取当前剧本、设定、采用素材和用户最新反馈，找出本轮要改变的内容与必须保留的内容。区分用户认可整张图、认可某项设计和只是提出候选。旧图片与新设定冲突时，明确旧图仍能控制哪些部分；不能将互斥信息一同交给模型自行取舍。

美术要求应能落到画面证据：年代和技术水平怎样影响设备形制，场所用途怎样影响布局，人物身份怎样影响服装和声音。风格词只是方向，不能代替这些事实。局部清理沿用户认可的主要设计进行，检查是否误删功能、空间密度或关键道具。

## 让每份参考承担明确用途

身份、造型、空间、材质光色、机位构图、屏幕内容和音色可以分别由不同素材提供。每个维度说明主要依据及辅助依据，冲突先解决再挂载。参考应足以完成本镜任务，不为凑齐整套资产加入无关局部或相反构图。

跨视角检查用共同地标、前后面、遮挡和接触关系；方位名与文件名只是索引。换机位会改变画面左右，不应改变家具朝向或物件数量。画外未覆盖的事实用明确来源补足，不能把“没看见”写成“不存在”。环境生产步骤见 [05](../05-image-references.md#场景素材生成)。

## 来源改变后更新哪些地方

先修改拥有事实的来源：剧情和感知权限归剧本，稳定外观与声音方向归设定，取景和动作边界归分镜。随后查引用关系，更新受影响素材状态、提示词全文、参考清单、节点输入与配置。派生 JSON 或汇总表同步当前版本，不成为另一套互相矛盾的事实。

旧版保留来路并标为已替代，断开当前镜头的废弃输入；不在继续有效的正文中混放相反设定。不能完成更新的部分明确标为待同步，停止受影响的提交。修完后回读真实输入，检查采用路径与正文是否一致。

## 证据支持多大结论，就记录多大结论

| 已取得的证据 | 可以确认 | 仍不能据此确认 |
| --- | --- | --- |
| 任务成功、媒体可解码、实际尺寸与音轨 | 技术产物存在 | 美术、动作或声音符合要求 |
| 原尺寸图、关键帧与空间依据的对照 | 当前可见布局、身份、文字和静态状态 | 整段动作、看不见的区域和音色 |
| 原速原片、切点与动作过程 | 已看的动态、节奏和连续性 | 未听过的发声、其他台词下的声线稳定性 |
| 实际回听及角色间对照 | 已听样本的声线、发音、完整性和区分度 | 其他情绪与镜头必然复现 |
| 创作者明确采用 | 指定版本与用途被采用 | 后续换输入或重生成仍自动通过 |

记录候选、限定用途可用、创作者采用和已替代状态。检查允许按用途完成，未完成项明确列出；不为了写“全部通过”省略证据缺口。静态帧可用与源视频可用可以得出不同结论。

## 让生产过程可恢复

实际提交前核对完整提示词、参考版本和顺序、模型、模式、时长、画幅与声音。格式校验有错误就先修复；校验与提交顺序应有明确阻断，不能在检查失败后继续执行生成命令。实际参数和任务 ID 记入作品，避免因刷新、空闲状态或超时重复提交。

新组合先在授权范围内做代表性验证。返工由具体证据驱动，优先修一个原因；多项同时变化时只评价整体结果。相同问题重复出现而没有新的修正依据时，停止原样重投。剧情或布局的关键冲突无法裁决时，向用户提交冲突与影响，继续独立工作。

素材生成过程与镜头生产默认分画布，当前输入保持简洁，历史证据保留在素材画布和作品记录。画布分工见 [08](../08-toonflow-generation.md#素材交接与镜头画布)，授权与恢复见 [生产路由](production-routing.md)。
