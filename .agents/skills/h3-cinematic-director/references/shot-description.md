# 镜头描述：空间、动作与声画

仅在设计、整体改写或对应问题返工时读取相关章节。局部格式修改不必重读。采用结论回填分镜与提示词；H3 字段与标签按 [格式入口](../../h3-prompt-writing/SKILL.md)，部署参数按 [本地能力](../../../../docs/workflow/references/local-model-capabilities.md)。

## 一段视频内切镜

- 用全局参考定方位、人物朝向和互动区域，用局部参考定道具位置。每次换视向，按实际机位推导可见背景和画外范围。反向广角按需挂入，平面图的方位字和标注留在参考图上。
- 用 `[Shot N]` 标记每个独立镜头，连续运镜留在同一条里。给每个景别一个清楚的观看任务，例如读画内信息、看表情或看接触动作。用动作阶段、视线或声音接镜，避免切后从头演。
- 通用构图句要限定适用镜头。「脸和手保持入画」只用于确实需要同时看见它们的人物镜；手部插镜、背影镜和空位揭示按各自的画框写。复核开头的通用要求是否与后面的逐镜描述冲突，删去不适用的句子。
- 纯插镜要写清画框止在哪里。只写「特写」或「边框入画」，生成时仍可能带进人物和周围空间。需要只看屏幕、纸面或仪表信息时，写清画框落在信息区内，并限定人物和环境参考适用的镜头。切回人物时再交代机位和动作。
- 人物和物件的位置按共同布局，景别和运镜服务当前动作。描述观众看到的取景效果和变化，例如在人物停顿时向脸部缓推。器材只在剧情需要它出现时才列为画内物件。
- 主观镜先确认观察者的位置、眼高和视线终点，再选同向的参考。写出必须入画的地标及其画面左右顺序。其他朝向的全景可用来核对布局，当前画框仍按实际视向定。
- 反应按触发和先后写，交代哪一处先动、停在哪里、何时开口或切镜。灯光或特效随表演变化时，写清变化由什么触发、持续到哪里，以及关键信息何时可读。
- 若实际片长有上限，核对所用工作流如何把设定时长换成帧数。按帧率和取整方式预留余量，出片后以文件实测为准。具体预设、帧数和实测时长记在作品制作记录里。

## 人物动作与环境关系

动作、周围物件和取景必须在同一个空间里成立。只列「人物伸手」「手和物件都入画」还不够；漏写距离、高差、遮挡或接触关系，会留下多种相互矛盾的实现方式。样片出现姿态改变、物件移位、肢体拉长或穿越障碍时，先检查提示词是否要求了彼此不相容的动作与构图，再核对参考图；不要直接归因于模型不稳定。

按本镜实际需要检查四件事，不把它们变成每镜都要填满的新模板：

1. **起点在哪里。** 人物的姿态、朝向、支撑点和手中物是什么；与将要互动的物件或人物相距多远、谁高谁低，是否隔着桌沿、门框等障碍。动作有依赖却未交代的关系才补写。
2. **动作怎样到达。** 从哪个部位、哪一侧开始，沿什么方向移动，是否需要转身、迈步或转移重心；在哪里接触、停住、放下或收回。区分画面左右、人物自身左右和场景方位。前后状态之间要有可行的路径，不能让物件主动移位来迁就动作。
3. **镜头实际能看见什么。** 从当前机位、角度与景别，起点、关键接触和终点能否被看清，哪些部分会被遮住或出框。需要更多空间就适当放宽取景、换合理角度或让次要物件部分出框，不要求人物改变既定姿态来凑齐所有元素；状态需要保持，不等于每件物品都必须入画。
4. **切后还成立吗。** 按下一镜的实际视向重算人物、物件和动作阶段，核对高度、距离、视线与持物状态。坐下、屈膝、越过障碍或伸手接触带来的身体变化，应与目标位置相称；切镜本身不能代替缺失的位移或动作。

修订先针对有证据的关系歧义，不机械增加机位数值或否定句。用原片或关键帧对照同一动作阶段，判断人物和环境是否保持合理关系、观看任务是否完成。用户反馈、文字风险与修订后实测分别记录在作品中；尚未出片的改法保留为待验证项。

## H3 的构图注意：动作主体与辅助元素

本地样片中出现过辅助元素挤占动作主体的情况。写作时区分「需要保持的状态」和「观众必须看见的内容」，两者不必全部落在同一画框里。

- **先写这镜要看清的动作。** 用谁的哪个部位、怎样移动、在哪里停住确定拍摄主体，再围绕动作路径安排机位与画框。「拍腿面」「拍桌面」会把这些区域列为取景目标，不能把它们仅当作解释人物位置的补充话。
- **辅助元素只交代必要关系。** 椅面、地板、门框或另一只手用于证明支撑、距离或状态时，只留足够辨认的局部，或明确它们保持在画外。不要为修一个空间问题，把所有相关部位和物件都提升为必须完整展示的内容。动作分解也要服从取景：胸上近景里的走近可通过上身位移、肩部与衣发跟随表现，不必展开髋、膝和双脚的完整动作过程，诱导镜头拉远去展示它们。
- **机位词和参考图分别检查。** 「右前方」「高角度」「俯拍」要与人物朝向、实际观看目标及遮挡关系相符；仅写方向，不能说明动作为什么可见。布局图或道具俯视图只负责位置时，明确取其物件关系，拍摄角度按本镜描述；不要无意中同时要求参考图的视角和另一个机位。
- **身份与表情镜先保证脸的可读性。** 需要读眼神、嘴型或表情时，写清画框边界，例如从头顶到上胸，背景只留必要局部。人物在场景中离对手较远，摄影仍可近取，不必让人物走近来迁就镜头。全景用于空间建立、走位或空位揭示；承担这些任务时，检查对应地标和动作是否可读，不要求每镜拍清面部细节。

## 环境描写与动作描写

在模型规定的画面描述字段内，先用一小段交代共同环境，再按镜序写动作与对白，不新增顶层字段。段长和信息量决定写多少，无需凑固定比例。

1. **环境写共同条件。** 只留会影响表演和连续性的方位、地标、光向，以及人物与互动道具的相对位置。明确哪张图定布局、哪张图给材质光色、哪张图才负责实际构图。远处陈设或画外物品可以留给参考图。共用条件集中写一次，镜头改变视向或碰到物件时再写相关局部。
2. **动作写可见的变化。** 每个 `[Shot N]` 先交代取景和开镜状态，再顺着触发、反应、行动、结果写。先说观众需要看见的脸、手、视线或接触点。动作跨切镜时接上一镜的阶段，避免切过来重新演一遍。道具出了画框仍留在原处，等剧情需要它时再进入画面。
3. **对白写在表演里。** 把说话人、对象、视线和口气写在台词旁，写清动作发生在开口前、句中还是说完之后。用短停顿和表情交接下一镜。遇到手持物，写清谁用哪只手、何时拿起或松开、最终留在哪，并只在声响实际发生处强调拟音。

人物显得僵硬时，选择当前画框内可见的身体过程：视线或呼吸先变化，肩、肘随主要动作移动，衣料和发梢稍后跟随并落稳。转头带动发梢，伸手牵拉袖口；不把衣发写成无风室内持续飘动。能同时发生的动作与对白并行，保留承担情绪变化的停顿，避免每个小动作都慢演一次。非实体人物的可见运动和现实接触、拟音分别按剧情设定处理。

片段拖慢时，先核对实读对白、关键动作、无效停顿和重复表演，再调整生成目标时长或剪辑入出点。保留剧情所需的反应与尾音，不用新增无关动作填满时长，也不套用固定压缩比例。分镜镜长、节点目标秒数和输出实测时长分开记录。

## 状态变化与特效

先区分发生变化的是位置、形体可见性、外观纹理还是光色，再写变化前、过程和终态。例如原地形成一个形体，就先写空位，再写局部形体建立，最后写完整形态稳定；如果只是衣服变色，人物从开镜就可以在场。避免用含糊的「出现」「浮现」同时代替入画方式与视觉变化。

主体定义交代身份，保留分析写稳定属性，逐镜正文写阶段变化。共同条件只写全段成立的事实，终态限定在变化完成后。跨镜沿用的特效在视觉设定中统一颜色、范围与强度，需要增强或消退时交代触发条件。

## 手机竖屏的上下遮挡

竖屏画面按目标播放界面给顶部和底部留余量，再按实际遮挡和镜头职责调整。优先保证眼神、口型、关键手势、剧情道具和画内文字可见。需要看完整头部时，把发顶和下巴都纳入画框。上下边缘多留给背景或非关键细节。

把播放端的遮挡范围留在分镜和验收说明里。生成正文只写画面构图和要看清的内容，例如「顶部和底部留给场景背景，脸与关键动作安排在画面中部」。播放界面的文字容易被模型当成画内元素，验收时检查有无多余的状态栏或界面图形。

同一镜要看脸和手时，先按完整头部定取景，再让关键手势位于脸下方的可见区域。需要时适当放宽景别，保持同一观察方向和人物站位。
