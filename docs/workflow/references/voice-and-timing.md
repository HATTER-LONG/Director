# 配音与时间对齐

两种制作模式涉及 TTS、变速、语音识别或字幕时间时读取。本页维护声音处理和时间映射，不决定哪些台词用 TTS、哪些需要人物说话视频；这由作品的制作模式和逐句声音分工决定。

## 语速只从明确的基准调整

生成时的时长系数、后期播放倍率和字数预算是不同概念。配音按当前引擎的正常语速基准生成，保留清楚完整的原音与实测时长；素材生成结束后，如需变速，在已选后期时间线上对选定片段应用一次已选倍率并保留音高。原文件不预先变速，避免生成、音频预处理和时间线各加速一次。素材与后期的资源安排见 [先生成素材，再集中剪辑](production-principles.md#先生成素材再集中剪辑)。

例如用户指定“正常语速的 1.2 倍”，IndexTTS 生成时显式传入 `durationFactor=1.0`，后期将选定原音的播放倍率设为 `1.2`。使用 Remotion 时核对所用组件的保音高行为；使用 FFmpeg 等已有工具时采用对应的保音高处理，并核对导出结果。不为变速另换剪辑工具。`1.2` 只是示例，不是所有故事的默认值。其他引擎采用各自可核实的正常基准；当前入口默认值不完全相同，见 [IndexTTS 部署核对](local-model-capabilities.md#indextts-25本地参考音频配音)。

先只修剪不需要的头尾空白，保留句内换气和语气停顿。TTS 音质、声线年龄、句尾及易错词在最终速度下回听。需要重生成时核对实际请求和返回参数，不能只看 UI 名称或“生成完成”。已采用 H3 的画音同步和速度单独处理，不随旁白倍率一起改。

与 H3 共用显卡时，配音批次前后按 [TTS 与 H3 缓存释放流程](local-model-capabilities.md#tts-与-h3-切换时释放缓存) 检查空闲状态、分别卸载独立服务的模型并复测内存；不要让下一类任务与上一类模型的闲置占用叠加。

每段记录原音、生成参数、实际时长和后期播放倍率；精确停顿也在时间线上安排。重录、裁切或变速后，重算受影响画面长度、字幕及下游时间线，并在最终速度下回听；以实际编码帧数收尾，避免累积取整误差。

## 分清台词、发音和停顿

同一段保留已确认的台词原文与实际合成输入，两者按段号对应。标点分句和发音标注属于合成处理；增删词、改变说话人或改写笑点仍是剧本修订，先按授权更新来源，再同步字幕。

是否使用情绪控制沿用作品的已确认选择，不为试标签重录已采用音频。需要控制情绪时，使用所选引擎的真实入口：IndexTTS 2.5 的独立情绪文本已接通 Toonflow；Breeze TTS 2 可从 Toonflow 的情绪配音／各角色参数输入，底层使用参考声线与独立 instruction。ComfyUI 也可直接使用 Voice Direction。具体标签、参数与未接入能力分别见 [IndexTTS 2.5](indextts25-guide.md) 和 [Breeze TTS 2](breezetts2-guide.md)，不跨模型套用。

| 要调整的内容 | 处理方式 | 核对重点 |
| --- | --- | --- |
| 声线身份 | 使用该角色已选参考音频 | 叙述者、父母和孩子各自绑定，沿用已采用声线 |
| 多音字、姓名或少见词 | 先定位确认的误读，再在合成输入中作最小发音标注 | 使用当前版本支持的格式；字幕仍保留原汉字；不把 ASR 字形差异当成误读证据 |
| 自然停顿 | 先按句意调整标点和语义分组 | 不能保证逗号等于固定毫秒数；不要把每个短语都切成独立音频 |
| 精确停顿 | 在完整语义边界拆段，分别保留自然收音，再在剪辑中加入明确时长的空白 | 停顿计入镜长和字幕时间；听接缝是否截断辅音、换气或尾音 |

运行参数与默认值以 [部署能力](local-model-capabilities.md#indextts-25本地参考音频配音) 为准；发音与标签用法见上方各引擎指南。不把其他引擎的 `[pause]`、`[laugh]`、SSML 或括号表演提示直接套进当前输入；文档、节点 schema 与实际请求都没有支持依据时，不宣称它们有效。Breeze 多人节点可在轮次之间插入指定长度静音，但不提供任意句中位置的精确停顿标签。

试配选短句、长句、问句和确有风险的读音，保留对照样本及一次改了什么。用户已采用某版后，锁定其文件与参数；只修已确认的问题。已要求停止识别纠词时，不再用 ASR 分数触发改词或重录；之后若确需识别来定位字幕时间，也不改变采用的文字与声音。

## ASR 用于查漏和定位，原声决定发音判断

字幕文字沿用已定剧本。ASR 提供原始转写与时间点，用来发现可能的漏词、重复、截尾及错读；不直接把转写结果覆盖成台词。

| 检查结果 | 处理 |
| --- | --- |
| 数字写法、确认同音的字形或儿化转写差异 | 对照原文和原声区分文字形式，不为匹配率重生成整段 |
| 不合理的极短附加词、零时长词或静音处识别出话 | 核对原声和语音区间；必要时换识别模型复核，置信度只作线索 |
| 可能漏字、重复或错读，尤其声调与音节有差别 | 回听对应区间。问题确认后才改发音控制、分句或相关输入，再比较新旧结果 |
| 多次转写仍有歧义，且不能实际听审 | 保留原文件、候选和未决位置，明确尚未确认；继续不依赖它的工作 |

模型支持发音标注时，仅在 TTS 输入里加入实际支持的拼音、声调等控制，字幕仍写原汉字。标注被接受、另一模型转写一致或局部音高下降，都不能单独证明读音正确。相同疑点连续重生成却没有新依据时，停止原样重投，回到听审或更有区分力的对照。

Whisper 的词时间戳可用于初步对齐；将词内多个字均分或插值属于估计，不称为逐字强制对齐。短句、停顿和句末要对原声检查。变速时将字幕映射到最终媒体时间：源时刻先扣除裁切入点，再除以速度倍率，最后加上该段在成片中的起点；如已对最终音频重新识别，不重复换算。

## 拼接后核对实际音频长度

容器报告的时长与音频解码后的样本数分别核对。多段混合剪辑中，即使每个视频的容器时长正确，音频包的时间戳与实际样本也可能不一致，拼接后造成声音累计错位。发现差异时，先定位受影响段，不用整体变速把声音压到画面长度。

可从已采用的原音范围独立渲染音频，统一采样率，按剪辑帧数计算目标样本数，只补齐预留的头尾空白，再按样本拼接；声音处理与画面滤镜变化分开。混音前后检查总样本数，并将各段的声音波形与成片对应位置比对，确认没有累计偏移。波形比对验证时间位置，不代替原速听审或口型检查。

帧率与采样率不能整除时，按累计帧边界计算各段的目标样本边界，再取相邻边界之差，避免逐段取整累积误差。目标区间容纳不下完整发声时，应调整剪辑范围或回到已授权的语速处理，不能靠裁掉有效声音凑长度。编码后的少量尾部填充与剧情内部的累计偏移分开判断。
