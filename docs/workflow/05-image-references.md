# 05 图片与参考素材

要补角色图、场景多机位图、道具图或本镜关键帧时，读本页。资产图从视觉设定出发。本镜起始帧或收尾帧从已定分镜出发。

## 使用 Skill

- [short-drama-image-prompts](../../.agents/skills/short-drama-image-prompts/SKILL.md) 写资产图提示词。
- [short-drama-storyboard](../../.agents/skills/short-drama-storyboard/SKILL.md) 写本镜的冻结关键帧。
- [scene-asset](../../.agents/skills/scene-asset/SKILL.md) 设计场景俯视图、固定空间布局和多机位参考。
- 用 [toonflow](../../.agents/skills/toonflow/SKILL.md) 操作已配置的画布图像节点。项目明确采用独立媒体适配器时，用 [short-drama-produce](../../.agents/skills/short-drama-produce/SKILL.md) 预览、确认后执行。

## 操作

1. 确认这张图的任务。身份图要认得出人，场景图要交代地理，起始帧要落实本镜的机位和站位。先找现成素材，再补缺失项。
2. 资产图按 Skill 写入 `图片提示词.md` 或现有文档，使用 `IMG-...` 定位。关键帧提示词跟对应镜头放在分镜中。只写提示词时交付可复制正文和挂图清单。
3. 用户授权生成时，检查图像节点、真实输入、模型和预设，再提交。收回结果后检查身份、构图、光向及道具。选中的文件放回作品素材库或约定目录。
4. 回填实际参考的文件、版本、用途和顺序。`REF-...` 表示真实可读的参考，`PLAN-...` 表示待落实的挂图计划。计划用于准备提示词，投产前要核对对应文件。

## 场景素材生成

同一地点需要在多镜或多集中复用时，先建立一张带方位的俯视图，再用 H3 取得不同视角，最后从视频选帧制成可复用的高清场景图。

1. **先生成场景俯视图。** 用 `scene-asset` 从剧情提取人物走位、出入口、固定家具和主要光源。用 `short-drama-image-prompts` 写提示词，再用已配置的图像节点出图。俯视图标清东、南、西、北，默认北朝上，已有场景沿用原方位。标出门窗、通道和关键物件的位置与朝向。核对人物能否按剧情走到目标位置，定下这张图作为后续机位共用的空间基准。
2. **用 MiniMax H3 跑环绕或剧情机位。** 用 `minimax-h3` 核对本地节点的参考能力，按 [H3 提示词](07-h3-prompts.md) 编译，再按 [Toonflow 视频生成](08-toonflow-generation.md) 提交。把俯视图挂作布局参考，实际开场构图另行描述。能沿场景自然移动时，用连续环绕交代起始机位、移动方向、沿途地标和最终朝向。狭窄场景或只需关键角度时，直接做剧情用到的主视角、反打和局部机位。逐个写清机位在哪一侧、朝哪边看，例如「南侧机位向北看门」。同一场景各视角沿用相同布局、门窗位置、道具状态和光向。多镜按顺序写，具体切点交给 H3。
3. **从视频选帧，再用生图工具优化。** 用 FFmpeg 从 H3 原始视频导出对应方位的帧。挑透视稳定、画面清楚、能看见关键地标的帧。把低分辨率截图作为构图参考，用已配置的图生图或图像编辑工作流提高分辨率并补足材质和细节。按需加俯视图或已采用的场景主图作辅助参考。锁住截图的机位、视向、门窗、固定物件和光向。
4. **逐张对照再入库。** 将优化图对照俯视图和相邻视角，核对门窗、通道、家具朝向和主光。发现布局漂移时，回到对应机位补跑 H3 或重新选帧。通过后登记场景、状态、机位侧、朝向和版本，保留俯视图、H3 原视频、原始截图和采用图。下游分镜绑定对应方位的实际文件。

## 交付

给[分镜](06-storyboard.md)和 [H3 提示词](07-h3-prompts.md)提供当前参考清单。图片或关键帧替换后，检查引用它的镜头和提示词。
