# 生产路由与授权

图片、视频、配音和音乐共用本页的入口与授权判断。只写文稿、提示词或审查时不进入生产。

## 选择一个入口

实际生成沿用作品已选入口；新项目默认 [toonflow](../../../.agents/skills/toonflow/SKILL.md)，使用已有画布、节点和素材目录。视频操作见 [08 视频生成](../08-toonflow-generation.md)，当前本地模型范围见 [部署能力](local-model-capabilities.md)。无需为生成新建配置或转换文档格式。

用户自己提交时，交付提示词和参考清单，收到实际文件后登记，不声称已提交。若明确指定其他入口，先核对其实际能力再执行，不为缺失端口静默换模型、丢参考或改成文生。

## 单任务与有界批次

提交前把任务落实为可核对的提示词版本、实际参考、模式、参数、数量、输出位置和费用边界。用户已要求生成、修复或完整跑通生成检查循环时，在相应范围内执行，沿用已选入口和规格，常规参数由 Agent 核对落实。仅讨论预算、接受文稿或观看预览不等于授权生产；确有超出范围的选择时，先准备具体方案再请求确认。

批量生产记录镜号或素材范围、模型与规格、数量和停止条件。用户给出的费用、数量或重试上限必须遵守。已授权本地逐段生成与修订时，可以每段先生成一个 take，检查后按证据返工，无需用户另填每项重试次数。问题解决就进入下一段；同一问题反复出现且没有新修正依据时，停止原样重投，先排查输入或方案。付费任务有预算上限时，无法可靠估价就不能声称满足预算。

授权内的文件落位、参数核对和任务登记直接完成。改变输入、覆盖写入、费用、数量或重试时，判断是否仍在原授权范围；超出才暂停相关提交，展示变化并取得新授权。不把同一范围内的准备工作都变成新的确认轮次。

## 区分生成目的

分别判断图片素材、环境机位视频、声音试说视频、剧情试片与正式镜头是否在授权范围。用户禁止正片段时，不提交同一剧情的低分辨率试片来绕过限制；已经单独授权的素材视频可以继续。用户禁止所有视频时，也不提交环境或声线视频。新指令只更新它涉及的范围，其余限制继续有效。

画布分工按 [05](../05-image-references.md#素材画布与验收状态) 与 [08](../08-toonflow-generation.md#素材交接与镜头画布)。用户明确要求沿用现有画布属于本轮执行方式，不改变跨作品的默认流程，也不产生额外确认要求。

## 小规模验证与恢复

新模式、工作流或关键参考组合尚未验证时，在已授权数量内先选有代表性的难镜头，核对身份、空间、关键接触、完整对白和可剪切点，再放大到剩余批次。已有同条件验证证据时直接复用；用户只授权一条时不额外生成试片。

记录任务 ID、实际输入、参数和产物。超时先查询原任务、队列或历史输出；状态未明不重复提交。终态失败后，在原授权及其上限内重试；保留旧 take。技术故障修好后复用既有输入；要修改剧情或分镜时，回到负责阶段，在用户已授权的改写范围内处理。

生产后完成当前任务已包含的结果核对、审查或剪辑；仅授权生成时不自动扩成整集制作。技术成功、媒体可用和创作者采用分别记录。
