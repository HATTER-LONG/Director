# 06 分镜与镜序

有剧本和必要视觉设定，需要拆场、拆镜或确定关键帧时，读本页。已有正式分镜且只需写视频提示词时，直接进入 [H3 提示词](07-h3-prompts.md)。

## 使用 Skill

- [short-drama-storyboard](../../.agents/skills/short-drama-storyboard/SKILL.md) 负责镜头卡和冻结关键帧。
- 多镜场次用 [shot-sequencing](../../.agents/skills/shot-sequencing/SKILL.md) 查镜序、轴线和动作承接。专项结论回填同一份分镜，不创建平行镜头清单。站位难定时可用 [novel-staging](../../.agents/skills/novel-staging/SKILL.md) 画俯视图；工具输入从当前 Markdown 提取，采用的走位句回填分镜。

## 操作

1. 读取当前剧本、目标场次和视觉设定。先决定观众每镜要看见什么，再选景别、机位和镜头顺序。
2. 多人场先定房间锚点、人物站位和轴线。换机位后重新推导画面左右、朝向和视线。
3. 给每镜分配稳定镜号，格式可用 `SHOT-<EP>-<镜序号>`。记录来源场次、镜头职责、起始画面、动作、可见终点、运镜、对白和与下一镜的承接。确认切镜的理由。
4. 先写清开镜取景与起止状态，只有需要专门构图图或精确落位时才补关键帧提示词，不要求每镜出首尾帧。检查 `REF-...` 实际文件和 `PLAN-...` 挂图计划。每份参考写明用途和顺序。缺图可回[图片与参考素材](05-image-references.md)。
5. 核对对白与动作能放进节点支持的总时长。分镜可记镜长用于规划。H3 提示词的具体切点交给模型，规则见 [AGENTS.md](../../AGENTS.md#h3-提示词项目规则)。

## 从计划到生产输入

素材未齐时可以继续设计镜头，用 `PLAN-...` 标明缺口；它不是可以直接提交的参考。镜头生成画布的搭建以当前所需素材已通过相应用途的检查为前提，按 [素材交接](08-toonflow-generation.md#素材交接与镜头画布) 只载入当前文件。资产仍在选型时，先完成分镜文档，不把所有候选接到镜头上。

反应镜核对触发者是否真的能被该角色看见或听见。主观画面、内心声与设备画面各按剧本边界设计；改变机位不会改变信息权限。上游事实变化后，先修镜头职责、动作和声源，再编译提示词。

## 跨生成段的剪辑接口

把每段最后一个可用镜头和下一段第一镜一起设计，并在现有分镜记录切点依据，不另建交接文档。

- **默认用切镜衔接**：前段以人物中景结束，后段用对手反应、道具插镜、不同景别或不同角度介入。根据观众此刻需要的信息选镜，不机械规定每段换人。通过视线、动作阶段、声音或因果承接；相同角色仍可换取景，避免同一构图、同一姿态的微小差异直接相撞。
- **明确两侧状态**：前段切在动作哪一拍、后段已进行到哪一拍；持物、光向、人物位置和情绪仍须连续。用反应镜遮切不等于允许道具或动作凭空改变。必要时给前后段留可剪余量，不强制所有片段增加时长。
- **必须接着同一人的连续动作**：按本地流程截取前段采用切点前的片段作视频参考，后段描述从参考末尾继续的姿态、方向、速度和新变化；不重演已完成动作，也不另强制尾帧图片。截取与实际读取范围见 [接续片段规格](references/local-model-capabilities.md#两段视频怎么衔接)。
- **先看接起来的效果**：验收对照两段切点附近和声音桥，判断差异是否可由换切点、缩短区间或现有插镜解决。需要新增镜头时先回到本镜的职责和已授权范围。

## 交付

更新现有镜头卡或 `剧集/<EP>/分镜.md`。交给提示词阶段的每镜都要能定位到剧本场次、起止状态和参考清单。生成前可用关键帧和临时对白粗排，优先解决观众看不清的动作和接不上的镜头。
