# 03 单集剧本

用户要求写、改或续写一集时，读本页。输入为单集任务、已有剧本或已确认的故事事实。

## 使用 Skill

- [short-drama-write](../../.agents/skills/short-drama-write/SKILL.md) 负责场次、动作和对白。
- [natural-zh-writing](../../.agents/skills/natural-zh-writing/SKILL.md) 用于检查中文表达和角色口吻。

## 操作

1. 定位目标集和用户要改的范围。检查上集留给本集的状态、本集转折及下一集需要接住的事实。
2. 按场写地点、时间、人物行动和局面变化。每场都让人物做出选择或造成可见结果。用可拍的动作承载关键情绪。
3. 区分画内对白、画外声和必须看见的文字。检查说话人、称呼和角色知道的信息。已确认的对白按原文保留。
4. 按项目目标朗读关键对白。给动作、停顿和反应留出时间。发现剧情或已有事实冲突时指出具体场次。

## 交付

沿用已有剧本文档和场次编号。新建时用 `剧集/<EP>/剧本.md`，按 Skill 使用 `EP001-SC001` 这类稳定场号。用户指定 Toonflow 中已打开的剧本文档时，通过 MCP 读写。将当前剧本交给[视觉设定](04-visual-assets.md)和[分镜](06-storyboard.md)。
