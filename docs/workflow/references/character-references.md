# 人物参考与身份依据

本页维护 Director 两种制作模式共用的人物参考规格。写人物设定图提示词、首次提交人物图或检查人物图时必须读取；本会话已完整读过且未变可复用。通用技能中的视图建议服从本页，用户当前要求和作品已确认的专用规格优先。

## 默认交付规格

需要独立身份参考的角色，默认每个角色、每套造型各做一张人物板，包含**一张清晰面部特写和站直的全身正面、侧面、背面三视图**。不得用多人合照、双人比例图、单个四分之三身姿或表情合集代替。群像比例图可以辅助比较，不作为各角色身份板。不可辨认的背景人群无需逐人建板；已有合格人物板直接复用，局部补图只补缺口。

- 面部特写采用正面平视：脸部正对镜头、双眼等高、鼻梁中线竖直、头颈直立、下巴端正，表情自然、嘴巴闭合。完整呈现发际、五官、下颌与必要配饰，不歪头、侧转、低头或仰头；身份取自用户参考或当前采用版本，参考中的表演姿态不照搬。不给特写加黑框。
- 三个全身视图为同一个人、同一套造型，站直、自然垂臂，头脚完整、比例与基线一致。正面身体和头部正对镜头；侧面身体与头部一起转为明确的侧身；背面背对镜头且不回头。三个视图都保持头颈直立，不用摆动、歪头或三个不同角度的正面姿态凑数。“正面平视”的要求只作用于面部特写和全身正面，不抹掉侧、背朝向。
- 使用纯色背景和便于辨认的均匀光线。面部特写与全身视图分区，大小足以分别检查身份与服装；具体排版沿用作品要求。
- 全身正面和侧面等视图中可见的小脸按下节加黑框；发型轮廓、体态、衣着与鞋履仍应可读。背面本来不露五官，不额外遮住后脑。
- 人物板不放剧情动作、手持剧情道具或镜头首尾姿势。风格图只作为画风参考时，不自动沿用其中人物身份；用户已要求沿用外形时再绑定相应角色。

## 写入与提交前核对

1. 在现有视觉设定记录角色、当前造型、身份依据和人物板用途；补充设计与用户已确认事实分开标明。
2. 在图片提示词逐项写明上述视图、站姿、背景、遮挡和参考分工，不能只写“人物设定图”“按规范生成”或把要求留在提示词外的说明里。
3. 提交前对照**节点内的完整提示词、真实参考与参数**，核对是否覆盖当前人物板规格。缺项先修正，不靠生成后解释替代。
4. 收回后看实际图片，逐项核对视图齐全、朝向、站姿、身份、造型和遮挡；面部特写另查是否正对镜头、双眼等高、头颈直立。生成成功只说明文件存在；不合格版本保留并注明缺项，补齐前不作为完整人物板接入下游。

检查结论与例外记在作品现有素材记录，不新增一套配置或每轮审批。用户已明确要求其他规格时直接遵从，并记录适用范围；仅有“少素材”“叙事动画”或画风标签，不构成省略人物板要求的依据。

正视与头颈直立用于身份参考板的相应视图，不限制正片中的表演。镜头需要转头、低头或倾听时，按分镜设计自然动作；不能把参考板规格扩成整片人物禁止转头。

## 人物多视图里的面部遮挡

本项目默认在全身视图可见的小脸上使用实心黑色矩形遮挡五官，保留独立面部特写作为脸部身份依据。黑框只覆盖小脸，不遮住用于辨认的发型轮廓、服装和身体。已有素材里的有意遮挡应保留，不当成损坏或缺脸自动补画。

下游提示词说明面部身份取自特写，全身视图只提供体态、服装、背面和装备信息；黑框、多视图人物副本和版式不进入正片。该做法来自用户的 H3 生产观察，减少多脸干扰的效果与改善幅度仍需同条件验证；项目制作约定不等于模型效果保证。
