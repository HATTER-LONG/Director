# MiniMax H3：文档与模型衔接

目标模型为 H3 时，用本页把 `视频提示词.md` 的镜头条目交给模型格式入口。已确定模型不等于选择文生或授权生产。

## 唯一格式入口

读取 [h3-prompt-writing](../../h3-prompt-writing/SKILL.md)，按实际模式选基础或 Ref2VA 指南，应用 [Director profile](../../h3-prompt-writing/references/director-profile.md)。描述语言按该 profile 和用户要求选择；对白、歌词和画内文字保留原文。字段、参考标签、对齐声明、切镜时序和对白结束符不在本页另立一版。

模式与有效时长从当前节点、API 或已核实的制作档案读取。没有运行证据时标为待核对，不把托管 API 的整数秒范围、分辨率或参考数量当作本地节点契约；不为适配规格擅自改已定镜长。

## 文档槽位到真实输入

- `REF-...` 指向真实素材；`PLAN-...` 仅是准备计划，不能宣称已挂载。
- 当前本地参考优先：完整身份、造型、地理、道具、动作与声音参考分别说明用途。单图不锁首帧，状态参考不保证端点对齐，不要求逐镜生成首尾帧。
- 按实际端口和挂载顺序编排 `<Picture N>`、`<Video N>`、`<Audio N>`，主体编号与素材编号分开。多张图属于同一人物时绑定同一主体，并说明各自保留哪些属性。
- 首尾帧输入能否与参考输入混用，由所选入口决定；无法绑定时停止相关提交，不用正文假装已接入。
- 保留分镜中镜号、动作边界、对白与上下游状态。提示词是同一镜头的编译结果，不重写来源分镜。

## 多镜与续接

一次生成包含多个镜头时，先验证当前入口支持的参考数量、模式和总时长。默认按 `[Shot N]` 交代因果承接；每切关键帧与精确切点仅在实际接口可用且本任务需要时采用，不以固定配额要求所有镜头补首尾帧。

跨段默认设计切镜，让后段从反应、细节或不同取景介入，避免独立生成的同构图姿态硬接。确需同一人连续动作时，按本地流程截取前段采用切点前的片段作 `<Video N>`，从参考末尾状态继续，不重复已演动作；完整人物和场景参考按需保留，不强制另挂尾帧。当前适配器只读视频开头且不接入视频音轨，裁切与声音处理按 [本地模型能力](../../../../docs/workflow/references/local-model-capabilities.md)。

## 对白与音频

用实读或已采用音频核对发声、停顿和反应时间，不把固定中文字数/秒当硬阈值。说话人与声线放在 `<d>` 外，台词放在相应动作处；画内有其他正脸时明确谁在说、谁不说，生成后核对口型归属。

音色参考会重新表演当前台词，源文件长度不等于新台词时长。复用已采用音轨时按官方保留语义说明声层、源区间和对应事件；需要逐样本一致时，以保留原音轨的后期结果验收。声音跨切镜与两个独立任务的无缝接续分别检查。

校验器通过只证明文本结构；投产前核对真实输入，出片后听完整对白、检查动作终点和接镜。故障诊断按问题读取 [minimax-h3-prompt-writer](../../minimax-h3-prompt-writer/SKILL.md)，本地配置问题再读取 minimax-h3。
