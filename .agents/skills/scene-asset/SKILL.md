# 场景设计与空间检查

本技能提供场景设计方法。Director 的环境生产次序按 [05 图片与参考素材](../../../docs/workflow/05-image-references.md#场景素材生成)，生成范围按 [生产路由与授权](../../../docs/workflow/references/production-routing.md)。稳定空间和美术结论回填视觉设定，具体镜头机位回填分镜；不另建资产事实或审批流程。

## 0. 加载规则与映射表

先确定本次媒介与改动范围。首次建立或重设计资产按下方剧本依据、描述、状态、材质/光影/几何和适用模板完成；局部修改只执行受影响部分，编号/文件查询直接回答。同一上下文已完整读取且未变的材料复用，不为改一处重新跑全流程。沿用作品已有场景编号和版本，不另外分配一套编号。

| 节 | 设计内容 | 用途 |
|---|---|---|
| 1–5 | 空间描述、锁定规则 | 确定地理和可拍性 |
| 6–7 | 视图任务与描述模板 | 交给图片提示词与素材阶段 |
| 8–9 | 图像检查与相关限制 | 核对布局、美术和用途 |
| 10 | 场景交接 | 回填来源、空间、美术与检查结论 |
| 11 | 类型适配字段 | 注入成片提示词的对应段落 |

### 剧本先行与设计依据

首次建立或重新设定资产且用户提供剧本时，通读所提供的完整正文，理解世界规则、身份关系、剧情因果和时间线，再回到资产出现的场次设计。长剧本可分段读完并留简短连续性记录。局部修订复用本轮已读且未变的依据，只补读受影响原文、当前场次与必要前后状态；跨上下文或源文本变化时核对实际来源。不能只搜名称或读摘要就声称通读；只有片段时说明覆盖范围，未给剧本时依据当前描述设计。

内部保留简短设计依据：正文来源与阅读范围、相关场次、故事风格与成像方式、已确认事实、设计推定、关键未知。设计要能解释“为什么这个资产在此时此地是这个样子”；后文信息可帮助理解时代、身份与伏笔，但不能把后续损坏、受伤、天气或揭示结果提前带入当前场次。

用户与当前项目已经明确的画风优先；未指定成像方式时默认摄影写实，以可信结构、材质和光影呈现。悬疑、喜剧、奇幻等故事类型不自动等于某种画风。未提供细节或参考图时，从剧本与用途主动提出合理设计；影响剧情、身份、既有锁定事实的关键未知才需确认。一般颜色、材料、陈设、维护与使用细节可作有依据的设计推定，不一律退回待确认；推定不能冒充原文或用户已确认事实。

### 交付与成像模式

先确定本轮是空间设计、图片提示词、实际素材还是局部修订。只交付请求所需内容；尚未生成的视图写成计划，不填写虚构文件路径或声称看图通过。

- **环境素材生产**：按 Director 的 [素材流程](../../../docs/workflow/05-image-references.md#场景素材生成) 执行，复用已有可用阶段。本技能补空间与美术判断，不自行改变生成次序或授权数量。
- **主图与空间核对图**：主图建立视点、视觉落点和光色气氛；俯视、反向与侧向图交代相应布局。两者共享空间事实，不要求每张图同时承担全部任务，也不让核对图的均衡照明覆盖主图美术。
- **多机位**：需要同空间不同角度时读 [同空间多机位设计](references/scene-multiview-design.md)。按剧情覆盖与授权范围选机位。用户指定九宫格时交九个有效机位，不用装修变体或单图裁切凑数。
- **局部修订**：围绕给定图与用户反馈保留有效设计，只修改受影响部分，按用途检查结果。

新设计或整体改写按 [电影画面关系判断](references/cinematic-image-direction.md) 设计取景、空间、光色与细节；局部修订只读相关判断。用户和项目画风优先，未指定时才用摄影写实。

## 1. 描述维度表

设计依据按用途覆盖：空间类型与用途、时代/地点、使用者与活动状态、尺度、布局与必要设施、维护程度、材质、时间、天气、光照、色彩、空间层次、固定场景标志及使用痕迹。这些维度用于完成设计，不要求逐项印成清单或全部挤入提示词。

规则：按第0节区分剧本事实、设计推定与关键未知；只把用户或剧本已确认的维度记录为稳定特征，待审设计不冒充已锁定。描述按从整体到局部、从外观到材质、从静态到状态组织，并对应当前剧情节点。

场景主图先形成一句可见的视觉主张，再组织上述细节：观众从哪里看、先看到哪处、空间如何延伸、哪些明暗与色彩关系形成此地此刻的情绪。将选择落实为机位与取景、空间大形、光影分区、材质和细节密度；删除“电影感、氛围感”等形容词后，仍应能想象出有主次的画面。具体方法见本包参考中的“场景主图：从空间设定到电影画面”。

首次设计按“情绪与美术方向 → 空间大形和材质/色块组合 → 光影与取景 → 必要陈设和细节”展开。把风格词接到具体形状、颜色、明暗与观看方式上，不先把房间写成物件清单。摄影写实可以鲜明、浓郁、锐利或柔和；不默认追加“克制、低饱和、微弱、柔钝”，也不为避错把所有表达强度压平。已锁定场景只调整获授权的开放项。

### 从剧情到可见环境细节

按“场所用途与使用者 → 必要布局、公共/生活设施及陈设 → 使用与维护状态 → 天气作用 → 已发生事件 → 可见光照后果”推导画面。每项关键细节说明因何存在、出现位置和合适强度，优先让空间能承载本场人物行动；人读说明与提示词直接写实际可见结果，不堆空泛的真实感、生活感。

生活感包括使用、整理、清洁、维修、生产和自然作用，既可整洁有序，也可磨损凌乱。器具、家具、食物与衣物依据住户、职业、经济条件和正在进行的活动选择，不把例子变成固定采购清单。正常开放的公共空间依据时段与用途安排使用人群和设施；用户要无人空场、假期或停用状态时不强加人群，仍可用设施及使用痕迹交代用途。

天气必须落到具体表面与空间：积沙受地形、风向及遮挡影响，扬尘强度服从当前天气；雨痕、滴水、潮湿及反射发生在实际暴露或传递水分的位置，不因室外下雨就让封闭室内遍地积水。事件痕迹对应已经发生的剧情与维护历史；弹痕、破损、血迹、庆典食品等会暗示具体事件的细节须有叙事依据，不能凭题材标签添加或提前泄露后续情节。

## 2. 一致性/状态规则

同组视图共享平面布局、入口/出口、主光方向、固定标志、材质与状态。主图建立美术和主要空间；反打从主要观察区域的另一侧回看，交代主图未展示的对应墙面/入口，并通过共同地标核对关系。反打是另一个真实机位，不是水平翻转、同机位裁切或改变装修；具体站位由空间可达性与信息覆盖决定，不机械固定正对180度。未见区域按已知依据或候选补设计处理，不冒称由单图精确还原。用户只点名一张或一个局部时只交该项。

多机位共享空间布局、物件朝向与同一时刻的光源状态；每个视图只改变摄影机位置、视向、高度、取景与适用光学。复杂房间、L形空间、楼梯、夹层及多入口先记录连接关系和遮挡，再选机位；不得把画面左右当作世界左右，或靠镜像、搬动家具、穿墙及补门来得到新角度。参考图未显示的区域标为设计推定，不能把单图声称为已还原的完整三维空间。

变体规则：服装、受伤、昼夜、损坏等变化使用原编号后缀（如 S01b）并记录变化原因；不得悄然覆盖已审核版本。采用后的参考用于保持既定外观；需要改设计时先更新视觉设定、素材版本与下游引用。

## 3. 材质细化库

建筑混凝土/金属/木材、地面颗粒与湿度、植被层次、天空介质、水体反射、雾的密度与光散射。

关键材质写清对画面有作用的表面、反射、透光或使用痕迹；“电影级纹理、精致金属”等质量词不能替代具体设计。按观看距离取舍纹理，材质与光源、接触点、重力方向一致。

## 4. 光影规则

主光方向+环境光+阴影方向明确；室内注明实用灯与门窗传入光，室外注明时段/天气。按光源位置、遮挡、材质粗糙度和湿度说明受光与反射；雨夜室内分别核对窗外天光/路灯和室内灯的来源、方向及亮度关系，不把雨夜一律做成同一种蓝光滤镜。

场景主图的可读性与情绪一起设计：关键行动区、空间锚点和本张需要交代的结构可辨，次要区域允许进入深暗、柔亮或遮挡。用主光的方向与软硬、环境回填及实际遮光组织亮暗层级，避免全场等亮、等清晰；明亮柔和、阴天或低反差也能通过构图、色块与材质分层形成电影感，不强制硬光、深黑或轮廓光。

颜色先落在建筑、陈设、地表与光源上，再决定整体色调。说明占主导的色域、相邻区域的分离方式及必要的局部色彩落点；强调色、冷暖对比和高饱和均按画面目的选用，不规定固定色数或比例，不把灰蓝、青橙、去饱和当通用电影配方。区分材质固有色与当前照明下的呈色，同一场景跨视角保持光源与色彩关系；换机位不翻转真实光源。空间核对图可按需用更均衡照明，但不能把这种照明反向覆盖已定主图。

## 5. 比例、透视与物理规则

一点/两点/三点透视必须与机位匹配；地平线、消失点和人物尺度不能冲突。

禁止：结构断裂、无承重关系、穿模、悬浮、镜像/重复零件、透视与光影方向相互冲突。涉及手持、穿戴、打开或碰撞时，说明接触、比例、受力与状态衔接；文字任务交相应设计或提示词。只有本次已要求实际图片且现有视图不足以判断交互时，才提出必要补图，遵守用户指定的数量和范围，不因描述交互自动出图。

## 7. 资产提示词模板

适用模板：室内、室外、太空、城市、自然、废墟、幻想。

先按素材流程与用户指定范围确定交付视图，再分别编写主图、反打或按需机位图的生成输入。主图写完整美术与空间，反打继承同一基准并明确新机位和可见关系。优先描述想要的画面，把关键事实与必要保持项接在后面；长短和段落/结构化格式服从任务，不固定字数，不复制整个验收清单。已提供参考时写明哪张负责空间、哪张负责风格、哪张是局部目标；没有参考则明确当前设计假设。用户要求扩展多视角时，分为共享空间/美术描述与逐格机位描述，不让每格从头设计一套房间。

~~~
[交付类型、画幅]，[场景自然名称、剧情节点与希望呈现的情绪/视觉特点]。
[统一的建筑大形、材质/色块、光影主次与关键陈设]。
[本视图的摄影位置、视向、构图、视觉落点与空间层次]。
[必须保持的场景事实、适用参考职责及少量针对当前问题的约束]。
[本次确有需要且已核实的目标平台参数]。
~~~

每个模板须写入适用的设施/陈设、使用与维护痕迹、天气落点及当前事件状态，不机械填满所有类别。提示词使用场景和物件的自然名称，编号仅作后台绑定。

按已选模式交付提示词、实际参考图或诊断/局部修改及相应资产合同；多视角/状态图仅在本次用途需要时生成。单幅单视角任务只取指定视角；一张多机位参考板可含所需多格，不能把“一张九宫格”缩成一个视角。不把视频动作或台词写入静态资产提示词。

九宫格或其他多机位数量采用专项参考中的“共享场景＋逐格机位”模板；以下类型字段仅补充当前场所需要的信息，不替代美术方向与机位设计。

## 8. 质量检查清单

- [ ] 编号、版本、名称和用途唯一
- [ ] 首次设计已读提供的正文；局部修订已核对受影响原文与必要连续性；阅读范围和设计依据可核对，没有只凭名称套模板
- [ ] 第1节维度已区分事实、合理设计推定与关键待确认；当前状态符合剧情时间线
- [ ] 成像方式符合用户要求，无指定时采用摄影写实
- [ ] 视图用途、生成次序和数量符合本轮素材流程与用户范围，已有可用阶段得到复用
- [ ] 场景主图有能从画面关系读出的视觉主张，机位、取景、空间大形和视觉落点明确；没有退回无选择的正面空间展示
- [ ] 光影与色彩形成符合本场的层次；没有用统一灰蓝、满屏高饱和、全场等亮或通用雾光替代氛围设计
- [ ] 关键空间可辨且次要信息有所取舍；克制、明亮、低反差或无人场景没有被误判为必须加戏
- [ ] 锁定特征跨视角一致
- [ ] 多机位由同一布局推出，各视图有明确摄影位置、视向及不同空间信息；九宫格实际有九个有效机位，没有用同画面裁切、装修变体或不同房间凑数
- [ ] 门窗/楼梯/夹层连接、家具朝向、遮挡及光源在世界中的位置守恒；未见区域、推定结构与技术剖视已注明，不冒充已核实实景
- [ ] 主体比例/透视/结构正确
- [ ] 用途、使用者、设施及维护痕迹成立；生活感没有被偷换为统一脏乱或空洞样板间
- [ ] 天气影响的位置、方向、强度与材质成立，室内外光源和受潮边界明确
- [ ] 人群与事件痕迹符合本场状态，无新增剧情或后续信息提前泄露
- [ ] 材质可见且符合光源
- [ ] 接触、重量和阴影可信
- [ ] 关键面、朝向、开口/接口可辨
- [ ] 无多余肢体、物件、文字或水印
- [ ] 背景不抢主体且能辅助尺度
- [ ] 设计结论已回填现有文档，素材文件、来源、版本与适用范围可定位

按交付阶段检查：文字阶段核对设计自洽与来源，像素项目留作待检查；实际图片按用途检查，失败项记录返工原因。技术成功、检查可用、创作者采用分别按 [证据与状态](../../../docs/workflow/references/production-principles.md#证据支持多大结论就记录多大结论) 记录，不能相互替代。

## 9. 负向提示词

三层仅作内部风险来源，最终提示词只保留与当前画面有关的限制；用正面目标说明优先，不机械叠加整套负向。静态无人场景不写手指、肢体、台词或视频闪烁等无关项。

第一层（通用）：影响当前设计的变形、穿模、漂浮、无依据重复、非所需文字或水印。
第二层（scene）：空间折叠、门窗/楼梯不连通、透视错误、无来源雾光、无尺度参照、固定标志漂移。  
第三层（画质）：先按用户成像方式选择。摄影写实排除不符合目标的卡通化、蜡皮、合成渲染感；三维动画、二维动画/插画保留选定风格，排除结构错误、风格漂移或意外写实化。各模式按需要限制低清、遮蔽结构的过曝/欠曝、过度锐化；不一律禁止动画、卡通或真实塑料材质。

需要诊断具体错误时再读 `references/NEGATIVE-CASE-BOOK.md`；选用相关项，不把案例或数字参数当作统一配方。

## 10. 场景交接

将以下结论回填作品现有文档，不要求另交 JSON：

- **视觉设定**：依据与设计推定、固定布局、门窗连接、家具朝向、光源、材质、细节密度、状态变化，以及未覆盖区域。
- **素材与图片提示词**：各视图的用途、参考分工、机位、可见地标、保留项、实际文件与检查结果。
- **分镜**：采用的取景和调度；一张素材图的机位不自动约束后续所有镜头。

已有工具使用 `spatial_contract`、`visual_design` 或 `view_plan` 时，可从上述文档派生，保留来源与版本；缺字段不填假数据。派生对象不是事实来源，修改设计后先更新对应文档，再重建工具数据。

## 11. 类型适配字段

把当前镜头需要的空间、美术或状态交给对应提示词字段。正文用自然名称，后台引用沿用已有编号。提交媒体前按实际用途检查参考并核对授权；用户要求亲自确认的环节等其确认，其他任务不新增逐图审批。候选资料可以支持标明假设的设计稿和提示词草稿，不能冒充可提交的真实输入。
