# 视听语言专项

帮助当前阶段负责人解决一个明确问题：观众何时看见什么，人物怎样在空间中行动，镜头为何移动或切换。已有有效方案直接继承；小幅文字改动无需重做整场设计。

## 先确定观看任务

- 本镜新增什么信息、关系、情绪或后果？没有新增内容时，判断停留是否承担节奏或表演作用。
- 观众需要先知道谁与谁、人与物的位置关系？哪些信息是有意隐瞒？
- 关键动作、接触、表情和反应是否在画框内看得清？
- 下一镜接走什么动作、视线、声音或悬念？

缺少镜头任务时，先在当前分镜里补这几项；需要比较拍法时用 ai-storyboard-director。无需等待未安装的技能。

## 设计与复核

1. 从已定剧本和当前镜头起止状态确定观看任务；将“刚刚/即将”等时态变成可见残留、预兆或后果。
2. 先确定人物位置、朝向、可走通路和接触对象，再选景别、机位、焦点和取景范围。世界方位与画面左右分开记录，换机位后重新推导。
3. 固定与运动机位都可成立。运动时写跟随对象、方向、速度和停止构图；固定时写画内变化。无需为了视频属性增加运镜或环境运动。
4. 关键动作留出启动、接触或变化、反应与收势。接触可用近景说明细节，涉及重心与位移时补能看见支撑和双方关系的画面。
5. 每次切换保留必要的方向、视线、动作阶段、人物和道具状态。需要越轴或故意失去方向时，让观众能从画面或声音更新空间关系。
6. 按信息、表演和声音安排镜长与停顿。镜数、景别比例、固定镜头数量、构图位置不设统一配额。
7. 诊断结论写明证据、影响与最小修改；设计结论交回原分镜。只检查本次受影响内容及必要连续性，不附送第二套镜头表。

## 格式与风格边界

影片、摄影师、器材或动画风格只在作品已选或当前需要比较时引用，并说明可见作用。没有默认的 FPV、畸变、动画流派或摄影运动强度。

本技能不维护六段母稿、不强制正向或负向提示词。最终文本按目标模型技能编译；H3 使用 h3-prompt-writing 与 Director profile。内部设计信息应保全，外部字段不增加重复包装。

拉片时覆盖用户要求的完整区间，区分原片、抽帧与用户描述。参考无法访问时说明证据范围；不能把未观看的声音、运动或接镜写成已验证结论。
