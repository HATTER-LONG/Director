## 结构约定

AGENTS 负责入口、优先级和职责；模式文档负责阶段路径；workflow 与共用 references 负责生产方法；阶段技能负责创作或处理；模型资料负责格式与已核实的运行能力；作品目录保留具体事实和采用版本。专项检查结论回填负责文档，派生 JSON 与历史快照不另立创作事实。

已有重复内容以链接交接，新增经验先修原条目和调用入口，不为每轮失败再加一套长期规则。本页仅为审查记录，后续执行以所链接的负责文档为准。

## 同日后续反馈修订

用户反馈 TTS 情绪控制效果差、整片动态镜头制作耗时过长。已删除情绪参数的使用说明，当前流程将情绪控制留空；多音字标注、语速基准、语义分句和剪辑停顿继续保留。叙事动画的入口、默认承载表与生成步骤同步改为静图和轻量后期优先，生成动态镜头仅作备选，先复用已有素材，再判断是否值得补拍。

这次只修改文档，不改已采用配音或成片，不重新生成媒体，也不提交或推送。上述自测结果属于首次结构审查；本次 8 个修改文档中的 130 处本地引用及标题锚点检查通过，`git diff --check` 通过，已核对旧情绪参数用法移除且多音字示例保留。未重复模型试验，不宣称已有固定提速幅度。

## 同日整体复核后的修复

本轮按用户授权修复七项审查问题，以修复前工作区为基线保留已有未提交改动；同一 Agent 实施并复核，未做独立盲审。

- 内置剪辑器将拼接视频、PCM 音频及 Remotion 子进程临时目录放到成片输出目录下，正常结束或报错时清理临时目录；原始素材和制作中间文件保留。输出目录仍须位于磁盘。
- ComfyUI 备用客户端按任务状态判断完成，失败或中断立即带任务 ID 报错；支持音频回收，媒体流式写入同盘临时文件，完整下载后才替换目标。下载中断保留已有文件。运行说明明确实际地址与按原任务 ID 恢复的方法。
- 共用声音规则使用已选后期时间线，Remotion 保持可选；继续保留先生成后剪辑、原音留存、单次变速与保音高要求。
- 静帧剪辑参考不再因发音标注、文件名或转写差异要求重录，按原声确认具体问题后处理。
- 多机位场景可直接生成静态机位图，也可选环境视频取帧；两条路线共用布局、美术与交叉验收，仅视频路线要求源视频和选帧来路。
- 场景设计先读当前完整场次、相关出现记录和全局设定，有跨场依赖再扩读。中文写作技能入口由 287 行缩至 36 行，原有详细条目、例子和来源原文移到按需参考。
- AGENTS、项目恢复入口与写作交接统一使用已有制作记录中的续作摘要，跨会话保存有效来源、进度、未决项与下一步；生产任务另保留任务 ID 和采用文件，不新增记忆数据库。
