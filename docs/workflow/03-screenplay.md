# 03 单集剧本

用户要求写、改或续写一集时，读本页。输入为单集任务、已有剧本或已确认的故事事实。

## 使用 Skill

- [short-drama-write](../../.agents/skills/short-drama-write/SKILL.md) 负责场次、动作和对白。
- [natural-zh-writing](../../.agents/skills/natural-zh-writing/SKILL.md) 用于检查中文表达和角色口吻。

## 操作

1. 定位目标集和用户要改的范围。检查上集留给本集的状态、本集转折及下一集需要接住的事实。
2. 按场写地点、时间、人物行动和局面变化。每场都让人物做出选择或造成可见结果。用可拍的动作承载关键情绪。
3. 区分画内对白、画外声和必须看见的文字。检查说话人、称呼和角色知道的信息。已确认的对白按原文保留。
4. 按项目目标朗读关键对白。给动作、停顿和反应留出时间。发现剧情或已有事实冲突时指出具体场次。

## 感知与信息边界

当场景涉及主观形象、内心声音、远程通话或设备显示时，分开写清观众能看见什么、每个角色能看见和听见什么、设备能记录或显示什么。画外声只表示发声者不在当前画框内，不自动代表其他角色听不到。角色的反应必须由他实际获得的声音、动作或信息触发。

信息边界发生变化时写明触发事件和变化范围；接入数据、允许读取、显示形象和外放声音分别判断。修改这些事实后，沿 [变更传播](references/production-principles.md#来源改变后更新哪些地方) 同步下游，不能只在某个提示词结尾加一句否定。

## 理解检查

剧本需要审查或即将扩大制作时，可先做一次不带创作解释的理解检查：审阅者只读本版剧本，复述人物目标、行动因果、转折和结尾悬念，再对照已定意图定位误读。独立审阅条件不具备时如实标为自检。小幅文字修改只复查受影响段落，不固定增加审阅轮次；详细方法见 [short-drama-review](../../.agents/skills/short-drama-review/SKILL.md)。

## 交付

沿用已有剧本文档和场次编号。新建时用 `剧集/<EP>/剧本.md`，按 Skill 使用 `<EP>-SC<场序号>` 格式的稳定场号。用户指定 Toonflow 中已打开的剧本文档时，通过 MCP 读写。将当前剧本交给[视觉设定](04-visual-assets.md)和[分镜](06-storyboard.md)。
