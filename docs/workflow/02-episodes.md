# 02 分集规划

已有故事方向，要规划各集或整理已有多集剧本时，读本页。用户只要求改写一集且已有本集任务时，直接进入[单集剧本](03-screenplay.md)。

## 使用 Skill

使用 [short-drama-develop](../../.agents/skills/short-drama-develop/SKILL.md)。读 [分集设计](../../.agents/skills/short-drama-develop/references/episode-design.md)。输入是多集整稿时，按 Skill 的多集接入方法识别现有边界。

## 操作

1. 读取创作简报、故事引擎和已确认的集数、单集长度与制作形态。缺少这些参数时，把会影响分集的数字写成候选。
2. 按集记录开场局面、主角目标、主要行动、结果和集尾。标出本集改变的人物关系、物件状态或观众已知信息。
3. 从每集结尾读到下一集开头。核对行动与状态如何接续。检查铺垫有兑现去向，转折能由前面的行动推出。
4. 已有整稿时，从实际剧本提取分集事实。保留集号和原文边界，标出剧本与既有地图的冲突。

## 交付

更新已有分集地图。按 `short-drama` 布局新建时，用 `项目开发/episode-map.jsonl`，格式按 Skill。给剧本阶段一份单集任务，包含集号、开场状态、必须发生的事件、集尾和下一集的承接。
