# 项目统一视觉风格与图片重生成

Director 中先继承现有创作文档与授权。风格基准只在本次需要新建或改变时提出；工具记录仅作可重建的辅助数据，不覆盖原分镜，也不为局部修改强制创建另一份状态。

用于项目风格模板、人物/场景/道具设计、图像提示词与实际参考图生产。执行当前请求的阶段；维护技能、纯资料查询、剧本叙事和已有素材的只读诊断不触发资产生产。

## 继承或建立风格基准

先读取已有视觉设定、采用的参考与用户要求。媒介与风格已明确时直接设计当前资产，不新增模板审批。确需新建或改变视觉方向时，给出能判断的候选和取舍；涉及关键未定选择时确认一次，其余可在明确假设下继续完成文字方案。

风格试样只在已授权的生成范围内执行。记录采用的版本和适用范围；文本通过、实际样张通过与用户采用分别判断。局部修改不撤销其他有效资产，也不因增加本流程要求旧项目重新批准整套模板。

## 模板定义什么

根据作品主动给出一个可判断的视觉选择，不把“怎么写提示词”反问给用户。模板明确成像媒介与形体概括、边缘/笔触、主导色彩及落区、光影与曝光、材质响应、光学/成像特征；按题材取舍，不机械列满参数。2.5D须具体说明体积和透视保留多少、表面如何手绘化、边缘怎样处理，不能只写2.5D标签。专业风格参照与这些可见结果相互支持。

母提示词的风格核心供同项目全部资产复用；具体主体、布局、视图与当前照明状态属于资产层变量。日夜或机位变化按同一风格推导，不要求每张图相同配色面积、焦段或光位。保留用户已锁定的故事、布局、造型和摄影位置。继承的是明确的风格与参考职责，不是上一张图的全部内容。

在既有项目状态/资产合同中记录模板身份与版本、完整母提示词、实际样张及其职责、用户批准来源与适用范围；可使用 `visual_style` 字段，不另建平行状态。下游接收同一版本与实际正文，不能只交一个风格名称。样张尚未生成时如实标未验证；用户批准文本模板不等于实际成像已通过。机器编号、哈希与审核字段留在后台，不进入可复制生成正文。

## 质感以实际画面为准

- **主色可辨。** 为当前作品选择有特色的主导色域，说明颜色在人物、建筑、织物、地表或光源中的具体载体与面积主次。保留颜色密度与材质本色，不把“电影感”默认写成低饱和、灰蓝、灰雾或全图褪色。明确选择的黑白、低饱和与柔和风格可以成立，但须有清楚的明暗、形体与材料层次；不用全局提饱和或统一浓黄滤镜补救发灰。
- **光在塑形。** 写清主光从哪里落到哪里、哪些遮挡形成明暗大形、哪些表面产生反射回填。人物与背景、主体与邻近物件应有可见分离。允许有意的暗部和安静区域，不为全貌核对把主图各处均匀照亮，也不以压黑掩盖结构。
- **材料有差别。** 选当前可见的关键表面，写其高光宽窄、粗糙度、透光、反射和接触关系。木材、织物、皮肤、陶器、玻璃、金属不能共用一层灰雾或塑料亮面。细节集中于观看落点，远近层次和清晰程度随视图设计。
- **主动选择摄影参照。** 写实路线可有目的地使用 IMAX 大画幅院线摄影观感、ARRI 数字电影摄影、Kodak VISION3 胶片色彩参照、变形宽银幕镜头等专业表达。把所选参照连接到空间尺度、亮部过渡、黑位、颜色密度、细颗粒、散景或局部光晕，按作品形成一套一致选择；不为了避免堆品牌而删除有用的风格锚点，也不把多个系统无差别叠加。动画或2.5D只采用有助于其画面的摄影特性，保留已批准的媒介。名称是生成风格参照，不证明实际使用该摄影机、胶片、格式或分辨率。
- **完整风格先进入图片。** 先判断参考图本身能否呈现所选质感，再交给视频继承；不把发灰或风格未成立的图片交给视频提示词补救。提示词长短和段落形式服从实际表达，不设统一字数，不把审查说明全部塞给模型。视频保持项目既定结构，共用风格集中表达，逐镜只写必要变化。

## 根据缺陷选择局部编辑或重出

1. 查看实际图片和当时的提示词、参考，定位错误范围；区分身份、空间、风格与局部细节，不能只凭一次失败断言模型原因。
2. 大部分设计有效、缺陷可隔离时，可按本次授权局部编辑，明确修改区与保留项；修改后同时复核缺陷和原有有效内容。用于后续生成的仍须是检查通过的版本。
3. 身份、空间或整体风格错误且无法局部保全时，从合格原始参考重新生成。不要把含结构性错误的图片当作正确身份或空间基准；工具自动带入历史图片时核对实际输入列表。
4. 保留原图、编辑版与生成记录，不沿着持续恶化的版本无限修补。没有新的修正依据、达到重试或费用边界时停止相关生成，报告具体缺口。
5. 文稿、诊断和技能维护不授权生成；实际编辑或重出按作品生产入口与授权范围执行。

## 交接检查

进入资产设计前核对当前视觉基准与开放项；提交图片/视频任务前核对实际参考版本、用途和已知缺陷，保证缺陷没有被当作应保留的正确基准。出图后先看整幅主色、明暗、视觉落点与风格统一，再看材料、结构和细节。只有实际看图才可判断质感；结构校验、提示词自洽、已生成、内部像素检查和用户接受分别记录。
