# H3 内容取舍与多轮修订

新写、局部修改和整理长提示词都用本页。它维护跨作品的写作方法，不增加 H3 字段；格式仍按当前模式，Director 的语法差异见 [profile](director-profile.md)。下面的篇幅比例是可迭代的编辑约定，不是官方模型限制或经过对照验证的最佳参数。

## 先写本段视频发生什么

先在制作说明里用一句话确定：观众在这段视频中要看清、听清或感受到什么变化。多个镜头分别承担什么作用，也从已定分镜读取。随后直接写可拍的正文：**取景与开镜状态 → 谁因什么行动或说话 → 对方或环境的必要反应 → 可见终点与切镜条件**。没有状态变化的镜头也可以承载观察、等待或情绪，说明这段停留让观众看什么。

先完成这条内容线，再补必要事实和有依据的异常控制。逐字对白放在对应说话人和表演旁，不被长段外观、房间说明或禁令隔开。不能只留剧情梗概，也不为填模板逐项补焦段、关节、衣料和背景动作。

## 三类信息分别处理

| 信息 | 保留依据 | 放在哪里 |
| --- | --- | --- |
| 镜头内容 | 观众要看的动作、表演、反应和信息揭示，以及让这些内容清楚可辨的取景、声音和先后 | 逐镜正文；本段重点在 summary 简述 |
| 必要事实 | 本次执行需要的身份、参考职责、空间关系、感知权限和继承状态 | 对应定义或共用说明，相关镜头引用；不抄整份设定 |
| 异常控制 | 用户指出或样片已出现、且本段仍有风险的具体偏差 | 就近写一条明确状态或边界；全段成立的才共用 |

按语义分类，不按“没有、禁止、保持”等词分类。“手松开后物件落入对方掌心”可以是交接内容；反复写“物件不复制、仍只有一个、不能多出第二个”属于异常控制。正向写法也可能是补丁。关键接触、发声归属、感知权限和持续造型有来源就应保留，无须等模型出错才写。

完整参考提供信息，不要求把所有信息译成文字。保留足以辨认主体的锚点、参考职责与本镜容易丢失的事实；在近景中不可见且不影响动作的服装细节、远处陈设、未来镜头的状态不展开。参考本身有矛盾时先修输入，文字不能承担所有纠错任务。

## 内容与异常控制的篇幅

新写和每轮修改都检查本生成段，并逐镜查看是否有控制描述挤掉内容：

- **默认目标：镜头内容至少是异常控制的两倍。** 即在这两类文字中，控制约占三分之一以内。
- **上限：异常控制不得多于镜头内容。** 超过就整理后再交付；没有异常时不为凑比例补控制句。
- 字段名、标签、最低必要的引用与保留关系说明不参与比较。逐字对白、歌词和画内原文也不用于撑大内容篇幅。跨字段重复的外观、空间或防错说明仍要计入，不能移到定义、summary 或 soundscape 中规避检查。
- 先按语义短句估算；接近上限时，英文按词、中文按去标点字数复核，同一稿使用同一口径。混合句拆开判断其功能。不把所有必要事实都豁免：首次建立本镜必需的状态属于事实，超出执行需要的重复和防错细节属于控制或应删除的冗余。
- 必要事实另做精简检查：共用事实集中，逐镜只在辨认、动作或切镜需要时重申。整段达标，也不能掩盖某一镜大半在讲防错。

超限时先删过期、同义、无证据和本镜不适用的控制，将剩余控制并入正确动作或状态。仍写不清时检查参考冲突、机位是否成立、镜头是否承担过多任务；需要改变镜序、事件或对白则回负责阶段，在已有授权内处理。不得删掉必要对白、感知权限或动作环节来过关，也不得添加动作、延长视频或灌水稀释比例。

篇幅检查只判断文字主次。它不规定总字数、相对旧稿的压缩率或镜头秒数，也不能据此判定成片质量。语义分类由写作者或审阅者完成，格式校验器不会自动证明比例合适。

## 对应到 H3 字段

| Ref2VA 字段 | 本字段职责 | 避免累积的内容 |
| --- | --- | --- |
| subject_definitions | 同一主体的参考来源、识别锚点、必要稳定属性；音频与说话人的绑定 | 整段剧情、整间房细节、每张同人参考各造一个人物 |
| summary | 一小段说明任务类型、本段主要变化与关键参考关系 | 整集背景、逐句对白、再次列全部限制 |
| retention_analysis | 按已定义用途说明适用镜头、保留或变化关系 | 重抄外观，或用 fully_preserved 冻结本应变化的位置与状态 |
| detailed_description | 按播放顺序落实取景、行动、对白、反应与结束 | 参考清单、返工历史、每镜重复的全局禁令 |
| overall_soundscape | 本段实际存在的底声与共用声音关系 | 无关人物声线、未来镜头音效、重复对白 |
| non_diegetic_music | 当前配乐意图；无配乐用 N/A | 用配乐填补叙事或未授权的声音层 |

T2VA 与实际支持的关键帧模式把同一内容线放入 `integrated_multimodal_description`，保留所需对齐声明；文生时补足必要静态锚点。不要为了精简去掉模式规定的字段。上述篇幅分类、修订理由和证据记录留在生成正文之外。

同一人物的多视图或构图帧仍绑定同一 Subject。图片若独立承担构图锚点，按所选指南为 Picture 声明用途及适用镜头，不能因此新增一个人物。构图参考只保留指定机位、左右关系和画框；表情、口型、屏幕内容、道具状态另按当前分镜与对应参考，不把截图整帧偶然状态一并固定。

## 多轮修改先替换再整合

1. **读当前完整输入。** 核对最新来源、整段正文、实际挂载与相邻镜头；明确要保留的内容和本次缺陷。不能从上一轮的修改摘要继续叠句。
2. **选修改范围。** 单处错误就替换对应句，再通读全段。即使没有字面冲突，出现重复、主次倒置、参考职责不清或多轮补丁堆积，也应按当前分镜重新组织整段，而不是追加更细限制。
3. **先恢复内容线。** 原对白、动作先后、人物位置变化和终点逐项对回来源。场外、被裁切、不可被某角色感知分别表达，不借精简改变故事。
4. **筛选仍有效的控制。** 在作品已有返工记录中简记“偏差证据—适用范围—保留的控制—下次验收点”。重复出现且仍适用的留一条；不再适用的删除。位置或状态变化优先写完整先后，持续外观说明在哪些可见阶段保持，少写同义禁令。
5. **检查篇幅与绑定。** 用上节比例检查主次，核对所有字段、参考编号、说话人及真实输入。只改文本时沿用时长、模式和种子策略；不得为清理文案自行改变运行参数。
6. **同步一份当前版本。** 保存可比较的旧版，更新提示词文档、卡片及受影响引用；事实变化先回来源。用同一模式校验并回读，生成与否按授权；旧视频不能作为新文案已有效的证据。

例如某个既定“移位”动作生成了同一人物的两个形体，内容可重写为“原位置的形体完全消失，空位短暂停留，同一人物在目的地形成并站稳”，再用“原位置保持空着”作局部控制。只有剧情本来允许这种变化才这样写；正常走动不能被改成瞬移。若镜头必须证明没有残留，取景和验收要能看见原位置，单写“只有一个”不提供画面证据。此例说明组织方法，不代表已验证的模型保证。

## 交付前核对

通读后应能直接找到本段重点、每次发声归属、关键变化与收束；必要事实没有丢，控制没有喧宾夺主。再查字段语法、真实输入和保存结果。内容检查、结构校验、成片验证分别记录；新发现先留作品证据，能跨作品成立的方法再修订共用条目，不把每轮失败都变成永久禁令。
